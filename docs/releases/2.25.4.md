# 2.25.4

支持 DSH 0.2.2-rc.1、Node.js >=24.9.0。

- 修正自主活动对话摘要：当前请求答复完整性检查属于同轮恢复，不再将后续真实聊天成功回复归入内部任务而漏掉。真实看板/后台任务仍保持隔离。
- 自主活动按当前目标会话携带最多六条已确认附件送达回执，区分真实渠道回执与助手自述，避免把已交付内容反复当作待办。回忆工具也可按文件名找回同一用户回合的确认回执、前置接话和最终回复，沿用原账号与会话隔离。
- 回忆工具及滚动窗口的前置接话说明限定为回应当前用户的回忆请求；自主检索、核验旧结果和整理念头可安静进行，不要求开场或结果汇报。人物与关系设定不变，不加入固定口吻。
- 语音父子投递在自主活动摘要和历史回忆中仅计入一次，保留真实台词。

不改写旧会话日志，不补发消息，不将尚未验证的附件标为送达。
