## 兼容性

正式版，适配 DeepSeek Harness **0.1.2-rc.1**；Node.js ^22.19.0 || >=24.0.0。知识库挂载管理需搭配 **dsh-knowledge 2.4.0+**。

## 更新

- 内置任务拆解 Skill 更新为 1.2.0；匹配多阶段交付、真实依赖或授权伙伴专长时，主动规划分工，无需用户反复点名 Skill 或逐个 @。授权目录补充稳定 ID 与职责描述；主动选择仍由模型判断。
- 创建看板任务并指定负责人后默认提交执行；支持 autoRun=false 仅规划，简单问答和明确只讨论/等确认的请求不自动执行。
- 执行意图持久化，前置任务全部验收通过后自动接续；重复提交去重、启动前复核授权、最多三个并发，保留重启恢复与终态回调。
- 旧任务没有显式执行意图时不会因升级突然启动；撤回授权阻止未启动工作，队列不淘汰待执行记录。
- 看板取消阶段内狭小的固定高度滚动框，改为横向卡片网格、折叠和按需展开；手机筛选栏收紧，保留原配色，不新增动画负担。

## 验证

169 项自动化测试通过，覆盖四任务依赖链、重复提交、并发限制、重启与权限变更。60 条任务的隔离浏览器验证覆盖手机、横屏、桌面与深浅色共 6 组场景，包括筛选、展开、详情和提交模式。

本机已部署同一个本地构建包，逐文件和 SHA-512 校验一致；服务健康，3080 API 与 3081 门禁检查通过。


## 从 README 迁入的历史说明

### 1.9.0 更新：主动任务拆解与执行

- 匹配已启用的拆解 Skill 和授权伙伴专长时，主动拆分真实交付物、安排负责人及依赖，不要求用户反复说“使用 Skill”或逐个 @；简单问答和明确只规划的请求不自动执行。
- 工具创建任务并指定负责人后默认提交执行；前置任务验收通过后，后续任务自动接续。支持 `autoRun=false` 仅规划；已有历史任务不会因为升级突然启动。
- 执行队列持久化、重复提交去重、启动前复核授权，最多三个任务执行并发；提交后先返回分工摘要，不阻塞等待所有结果。
- 看板改为阶段内横向卡片排列、按需展开与整页滚动，移动端使用紧凑筛选栏，保留现有配色。
- 169 项自动化测试通过；60 条任务的隔离浏览器检查覆盖手机、横屏与桌面、深浅色共 6 组场景，包括筛选、展开、详情和提交模式。
