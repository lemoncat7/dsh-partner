# 2.27.1

- 普通最终回复与自主活动收尾共用 nextActivity：开启自主活动的归属会话收尾明确选择暂不继续，或依上下文选择继续接话、另开话题、推进事情、浏览探索或平台互动；不新增逐轮决策模型调用，不强制随机活动。
- 意图先等待本轮结束及真实投递确认，再由现有调度执行。默认不等闲时频率；新消息、撤权与失败重新核验，同一来源最多连续安排三轮，避免循环。拒绝可选意图不阻止正常回复。
- 自主活动记录显示最近的后续选择、依据与是否被接纳；选择不是执行或发送成功。空间浏览、互动、公开发布和私聊分享分别决定。人物措辞不写入插件。
- 延后计划不再阻塞其他正常闲时活动；持续陪伴的短接话不能通过另起活动绕过预算，安静收尾使用实际可用的 finish 入口。

- 普通聊天的后续意图也核对持久投递回执：安全重试仍等待，恢复确认后就绪，结果不确定则取消延续，不因原发送回调已退出而一直卡住。
