# 1.12.0

正式版，适配 DeepSeek Harness **0.1.2-rc.1**，Node.js **^22.19.0 或 >=24.0.0**。

## 记忆质量与恢复

- 记忆写入要求可验证的用户原话引用，避免把助手回答、临时过程或猜测写成长期事实；支持按目标记忆修正。引用校验不等于语义正确性证明。
- 明确事实和反复确认的稳定偏好分别进入画像；相关性检索不再用无关内容填满召回，补充有界场景和历史片段。
- 对话结束先持久化提炼任务，再由后台串行处理。重启恢复、失败退避重试、结果检查点和写入去重共同减少重复处理；通知仍不保证跨进程严格一次投递。
- 每日整理可提议场景摘要与有跨会话成功依据的经验草稿。经验需人工审核后导出，不自动安装 Skill 或授权。

## 记忆工作区

- 「持续关注」独立为伙伴标签页，保留引用文件/知识文档、下次检查时间和生命周期操作。
- 记忆页按画像、记忆、回顾分层，场景摘要与对话历史按需进入；经验审核和关系图谱放在「更多」。
- 记忆与心跳设置使用统一弹窗；展示后台处理状态并支持重试、记忆依据查看和手动修正。
- 按联系人隔离请求和结果；过期请求取消、隐藏页面暂停轮询、记忆条目分批显示、历史正文展开后渲染。沿用现有材质与字体，无新增装饰动画。

## 升级与边界

保留原有目录、配置和记忆；新增 SQLite 表为增量迁移。升级前建议备份伙伴数据。旧历史不批量迁入新历史界面，仍保留在原会话及历史档案中。

开启学习后仍按有效对话逐轮提炼；每日整理按联系人和待整理日期执行。尚未增加 token 用量统计、短消息跳过或合批策略，本版不宣称整体模型费用下降。

验证：308 项自动化测试、构建与 TypeScript 未使用导入检查通过；浏览器验证覆盖手机、平板横屏、桌面及深浅主题，检查联系人切换、筛选、按需读取和保存防重。此前本地部署已核对构建产物与 11 个记忆数据库完整性；未以真实渠道发送作为发布测试。

## 1.12.0 更新：记忆质量与工作区

正式版，适配 DSH **0.1.2-rc.1**，需要 Node.js **^22.19.0 或 >=24.0.0**。

- 「持续关注」成为独立标签页；记忆页按画像、记忆和回顾组织，设置使用统一弹窗，支持手机、平板与桌面。
- 记忆候选验证用户原话依据，区分明确事实、稳定偏好、一次性过程和持续关注，召回仅保留相关内容。
- 提炼任务持久化、后台执行、失败退避重试；已保存提炼结果复用，不因后续写入或通知失败重新调用模型。
- 提供场景摘要、对话历史、处理状态与经验审核；经验仅审核后导出，不自动安装 Skill 或扩大权限。
- 保留已有数据与权限，不自动清理旧记忆。当前仍按有效对话逐轮提炼，未增加 token 用量统计或短消息合批。
