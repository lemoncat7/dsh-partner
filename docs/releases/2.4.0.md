# 2.4.0 · 伙伴 MCP、能力管理与验收恢复

正式版。已验证宿主 DSH **0.1.5-rc.1**，Node.js **^22.19.0 或 >=24.0.0**。
保留旧宿主兼容声明，未重新完成旧宿主全部端到端验证。

- 新增 HTTP / stdio MCP 服务配置、JSON 导入、连接诊断、工具刷新与按伙伴授权；授权或工具目录变更在下一轮会话生效。
- 凭据独立存储，编辑默认脱敏；新凭据 ID 使用固定字母前缀，修复 UUID 数字开头导致随机保存失败，兼容已保存凭据。
- 能力修改自动保存，失败回滚并显示错误；Skill、可访问伙伴和 MCP 在对应卡片中打开管理弹窗。
- 管理弹窗按屏幕尺寸自适应，保存反馈不再悬浮遮挡内容。
- 任务规划明确指定验收伙伴；自动验收使用持久任务恢复，避免重复执行已完成的工作；未作出验收决定时显示可操作错误。
- MCP 服务支持文档见 [MCP 配置说明](../mcp.md)。升级前建议备份插件及数据。
