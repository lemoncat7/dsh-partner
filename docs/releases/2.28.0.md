# 2.28.0

- QQ 群聊接话模型由伙伴插件管理，开启时按需下载 MiniLM，关闭后释放模型进程。内置分类头可直接使用。
- 勾选多个群后可一键整理真实历史并训练共同版本，可切回内置分类头或共同的历史版本。训练页分别显示角色称呼、同名误接反例和设定相关场景的留出结果。
- 接话判断结合人物兴趣、经历和群内上下文，区分单人续聊与多人讨论。回复沿用人物设定，关系称呼仅用于匹配的已核验对象。
- 同一 QQ 群的分段回复按轮发送。已有更新回复送达时，尚未发送的旧普通接话会跳过。
- B 站渠道改由插件后端直接连接，公开查询可直接使用，登录互动通过渠道配置。自主联系会跳过已接过的旧话和近期重复内容。
- 伙伴配置支持搜索，也可让 AI 查找相关设置入口。

升级后重启对应的 DSH Profile。已有群训练版本可以继续使用，使用新版称呼和场景标注需重新执行一键训练。运行要求 Node.js 24.9 或更高版本。
