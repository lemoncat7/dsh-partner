# 2.8.4-style.2（本地体验版）

沿用知识库风格，继续统一表单密度与选择交互。适配 DSH 0.2.0-rc.2。

- 输入、搜索、筛选统一边框、圆角、字号、背景和焦点反馈；复合搜索只保留一层边框。
- 桌面单行控件 38px，窄屏 44px；开关、文件选择和其他特殊控件不套用文本输入样式。
- 伙伴能力中的 Preset / 提供方 / 模型收为紧凑摘要，点击“调整”进入统一弹窗。模型支持按名称与 ID 搜索，列表滚动而不是撑高页面。
- 保留原有自动保存、失败回滚、提供方切换清空旧模型、已有会话不被覆盖的行为；错误也显示在当前弹窗内。
- 记忆设置的模型字段在宽屏并排，窄屏自动换行。

回归：739 项单元测试；能力自动保存、切换模型、失败恢复、渠道表单、记忆页在深浅色与多种屏幕尺寸下的浏览器检查。
