# 2.21.5 · 好感度与主动延续

开启「闲时自主活动」及角色好感度后，正常回复成功送达会获得一次主动延续抽签。默认渠道沿用好感度适配器；QQ 只对已核验的归属账号生效。每个伙伴独立计算，多个归属账号共享同一进度；同一伙伴最多保留一项待执行机会。

概率为 `0.05 + 0.40 × (好感度 / 100)²`，20 分约 6.6%，60 分约 19.4%，100 分为 45%。这是唤起自主决策的概率，不是必定再发一条消息。抽中后可自然延续话题、发表情或语音、使用已开启的私有能力，也可安静结束。工具权限与原配置一致，不添加顶层工具，不增加每日联系上限。

随机等待 20–90 秒后，由现有每分钟自主调度检查执行；因此实际开始时间可能再延后不足一分钟。忙碌时短暂等待，超过送达后三分钟仍未开始则取消。待执行延续会暂缓同一伙伴的普通闲时抽签，开始后也会更新闲时活动时间，避免两个自主流程抢跑。

发送失败、静默结果、内部通知、主动延续自身不再触发抽签。每次抽签的命中和未命中都会持久保存，重启不重抽。任何会话的新输入、睡眠、取消归属、关闭好感度或自主活动、身份版本变化、目标会话变化会使旧机会失效；发送及 QQ 私有工具执行前再次核验实时权限。用户提出的安静、告别和停止要求由自主决策结合对话遵守，抽中也不强制发送。

网页正常回复在会话回合结束并空闲后登记；渠道回复在文本、表情与附件全部交付成功后登记。延续始终回到原始会话，普通闲时活动继续使用设置中的目标会话。

验证：概率边界、命中与未命中去重、并发领取、跨会话打断、忙碌/过期、原始目标、睡眠/权限撤销、归属群身份、持久化与发送成功/失败/静默回归；未向真实 QQ 发送测试消息。
