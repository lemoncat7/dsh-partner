# 2.25.15

支持 DSH **0.2.2-rc.1 / 0.2.2-rc.2**，Node.js **>=24.9.0**。

- 修正群任务被连续闲聊反复插入的问题。活跃回复按群与渠道跟踪；进入工具工作后普通群消息只旁听，不阻止工具，也不排队数分钟后补答。
- 任务发起人的明确取消、修改与补充可继续插入；明确呼唤的新请求排在当前任务后，准备队列不等待整个任务，后来的取消仍能处理。初始短句拼接只有固定 5 秒窗口，不随流量无限续期。
- QQ 公开回复支持附件交付：可发送本会话工具明确返回 `files[].path` 的产物与回复文档；保持工作目录、会话/渠道来源及重试目标校验，不开放任意私有文件或工作报告。
- 明确当前 QQ 渠道附件通过 `partner_send_attachment` 交付，避免把普通群号传入另一个 QQ 官方机器人插件的目标标识。外部工具入口和原有授权保持独立。
