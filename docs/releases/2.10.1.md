# 2.10.1 — 修复正式对话中的角色与记忆注入

修复角色试聊与正式会话效果不一致的一条实际原因：动态记忆原来作为系统提示区块注入，支持 in-history 更新的模型每次变化都能追加整份系统提示；渠道入口还会重复召回记忆、人物画像和旧助手原文。

- 稳定身份与聊天行为放在 DSH 的人格后缀位置，动态角色状态、相关记忆、画像与本轮提醒改为原生 runtime context，使用字面量文本。
- 本地、渠道和插话共用 awaited assembly 准备点，每条输入只召回一次。记忆关闭时不自动读取长期记忆或画像。
- 开启角色聊天时，自动召回保留结构化记忆、场景与画像，停止附带历史助手原文；显式 `partner_memory_recall` 仍可检索历史细节，旧身份的自动历史检索不变。
- 用户纠正语气时直接调整接话，避免自动写人格诊断、整改承诺和加粗小结。实际任务仍照常使用全部授权工具。

不改写原始会话，不增设回复改写模型调用，不缩小工具集。重启后的原生会话恢复会按 DSH 的新消息系列规则归一化旧系统快照；以后角色配置不变时，伙伴动态记忆不再触发整份系统提示更新。其他插件仍可能独立改变系统提示。

用户界面的引导示例保持通用。自然程度仍需真实多轮体验判断，测试通过不等于所有回复都能达到同一种风格。
