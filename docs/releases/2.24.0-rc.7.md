# 2.24.0-rc.7

“自主调整角色设定”替换为“自主习惯”。旧开关迁移为新开关，固定角色正文不再由自主活动或后台整理改写；用户明确要求的身份编辑仍然可用。旧自主修改历史保留存储，不再作为自动修改入口。

习惯单独保存，最多 12 条，每条最多 120 字，保留最近 5 条来源摘要。群聊和私聊的授权互动都可提供依据，不要求归属账号；默认按群或联系人隔离。自身已完成活动可通过 partner_habits 形成通用兴趣候选。三次独立来源、跨度六小时后生效，30 天无新依据不再注入。候选不影响回复。暂停、删除、失效基线和重复来源均不构成新的训练依据。

后台复用记忆提炼请求，支持近期真实用户原话作为证据，不再受旧六小时人格检查冷却限制。需要开启记忆学习。自主活动无需记忆学习即可使用习惯工具。模型仍可选择不记录；来源校验不等于对偏好语义的完整证明。

页面显示候选、已形成和已暂停状态、来源、检查结果，支持暂停、重新观察和删除。角色正文及关系等被手动修改后，旧习惯停止注入。发送前角色表达和工作表达使用对应场合习惯；公开评论仅接收通用兴趣，不带来源摘录。
