# 2.14.0 · QQ 分层配置与群聊

QQ 渠道新增分层设置：总览 → 连接/私聊/群聊/表情/权限/发送，群列表放在群聊的下一级。支持深浅色、小屏布局、明确的开关状态、草稿关闭保护及配置冲突检查。

群聊默认关闭，仅选择的群可触发；默认被 @ 才回复，可选择回复全部已授权成员消息。成员按群单独配对，群会话不合并私聊模型历史和会话记忆，群通知固定返回来源。现有私聊连接保持兼容。

提供私聊、群聊、回复 @、系统表情、图片/表情包开关，以及手动文字/原生 QQ 表情发送。目录来自 SnowLuma，支持分类搜索和预览，发送前核对当前 QQ 身份、群/好友关系及授权，等待 API 回执。浏览不会发送消息。

验证包括模拟 OneBot 的路由、权限、媒体及群上下文测试，手机/桌面深浅色浏览器检查和线上只读目录查询；没有向真实联系人发送测试消息。
