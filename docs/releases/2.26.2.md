# 2.26.2

支持 DSH 0.2.2-rc.1 / 0.2.2-rc.2，Node.js >=24.9.0。

- 表情常驻上下文改为收藏备注中动态提取的去重标签，不再注入图片 ID、名称或 URL。收藏、改备注、删除后清除对应渠道缓存，下一次模型上下文准备时刷新；外部手动变更随五分钟缓存到期刷新。
- 想用表情时按标签查询，默认每页 12 条、最多 24 条，可继续翻页；不要求每次回复查询。QQ 收藏详情同样分页返回管理 ID 和标签，内部去重仍使用完整上游结果。
- 查询收藏标签不再顺带读取系统小黄脸；明确 kind=all 才包含系统表情。QQ 上游收藏接口单次读取范围仍最多 200 项，total 表示本次读取范围内数量。
- 自主活动目录明确 QQ 空间发布与收藏整理的实际入口，允许从最近聊天和兴趣出发；无强制发布次数，整理后可安静结束。
- 保留角色设定、渠道权限、发送确认、群附件关联和短句规则。
