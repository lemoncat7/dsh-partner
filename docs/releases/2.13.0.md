# 2.13.0

- 新增 QQ 渠道，通过 SnowLuma / OneBot v11 正向 Universal WebSocket 接收好友私聊与发送回复。
- QQ 配置只需 WS 地址和 WS Token，提供连接测试与可选固定联系人；复用凭据库和联系人配对授权。
- 复用伙伴人格、记忆、工具、分段聊天、表情包及通知流程；QQ群消息不会触发伙伴。
- 共享收发连接、关联 API 回执、断线退避重连、检查登录账号与好友身份；按文本段发送，避免 CQ 字符串被解释为动作。
- 图片和文件以字节上传，兼容 DSH 与 SnowLuma 分属不同容器；发送结果逐项确认。

验证：TypeScript/客户端构建、841 项自动化测试通过（含 9 项 QQ 协议测试）；真实 SnowLuma 的 WS 连接与账号检查通过；QQ 配置弹窗通过手机/桌面、浅色/深色检查。
