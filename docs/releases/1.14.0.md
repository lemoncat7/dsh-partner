# 1.14.0

## 持续关注与记录

- 轻量后台检查继承来源会话权限，不创建临时 Agent 对话；检查与无工具收尾分阶段计时，保留逐轮耗时及脱敏诊断。
- 核验结果可通过检查点持久保存，记录同步单独执行。同步失败15分钟后重试，不重新调查来源或发送变化通知。
- 只写用户手动指定的现存笔记或文件，不通过知识文档引用推导写入目标。同步先读再合并，笔记使用版本校验；更换目标取消旧目标的待同步数据。
- 支持编辑关注说明、依据和记录位置，查看归档配置及确认删除。删除关注不删除关联文档。
- 手动检查异步返回，界面查询执行状态，避免长请求等待。

## 记忆与稳定性

- 同一联系人任务连续失败3次后，退避期间允许后续任务整理；失败任务仍保留并重试。
- 旧轮次补处理不覆盖较新的同主题记忆或日摘要。
- 展示完整积压数量、上次失败原因；模型错误保留脱敏错误码与HTTP状态。
- 会话恢复仅在确认持久化会话不存在时回退创建，避免重复会话错误。

## 升级说明

保留现有配置和数据，SQLite字段增量迁移。升级前建议备份伙伴数据。
旧轮次若没有完整结果快照，不能仅凭变化摘要补建文档，需重新核验。
同步写入仍需要有效权限和模型正常返回；外部写入与本地队列不是跨系统原子事务，不承诺严格一次执行。
