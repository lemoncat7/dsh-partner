# 2.21.3

- QQ 群聊改用会话归属、连续对话状态和可选本地语义分类，不再对正常接续逐条抽签。明确叫名、关系称呼、引用伙伴消息直接进入处理。
- 按群及发言人分别保留成功回复后的五分钟对话窗口，其他成员插话不会清空或继承；发送失败、旁听不延长窗口，明确转向他人或停止会结束对应状态。
- 分类不确定、忙碌或不可用时放行至正式回复模型。语义服务独立限额运行，支持中文及多语言编码，无额外远程大模型判定调用。
- 自主群聊允许通过原聊天回复入口提交空消息选择旁听，不发送技术提示；私聊、浏览器来源和非白名单群不能使用该路径。常驻工具数量和权限不变。
- 引用对象根据实际收发记录核验；本地判定显示具体接话原因。使用与评估范围见 docs/qq-attention.md。
