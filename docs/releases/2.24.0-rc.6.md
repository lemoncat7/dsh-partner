# 2.24.0-rc.6（测试部署）

此前可选的表达入口经常未被主模型使用，B站评论也未接入。本版在现有聊天投递工具和B站评论调用中自动进行一次只读人格表达，不再依赖模型主动选择 expression。

- partner_chat_say 的普通文字和任务前接话、partner_chat_reply 的文字、partner_bilibili 的 comment 正文均接入；已有 expression/workReply 不重复生成。
- 表达读取有效人物正文；聊天使用当前真实用户发言和最近双方对话。运行时上下文快照不能冒充用户新消息。公开评论不传私聊关系、私聊消息或私聊历史，并固定原视频/评论线程。
- 回执记录实际发送的文字，后续模型据此接话。指定且可核对的原文、代码、详细正文和纯表情/附件交付保持原路径。
- 保持文字和表情顺序；输入、人物、休息状态、回复对象或授权变化会阻止旧文字发送。
- 表达失败或超时保留原稿，不重做任务、不发送生成错误提示；显式表达已经失败时不再尝试第二次表达。
- B站写入去重绑定改写前的原始请求，防止同一评论重试时仅因措辞变化重复提交。没有增加任何互动权限。

此步骤通常增加几秒模型耗时，18秒超时。数字、链接及格式有程序检查，但语义与语气仍依赖模型，不能承诺每次完全符合人物。长任务权限、工作超时和上下文滚动机制未改变。普通最终文本及语音等未通过上述投递入口的路径不在本次自动处理范围。
