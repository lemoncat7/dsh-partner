# 2.25.3

支持 DSH 0.2.2-rc.1、Node.js >=24.9.0。

- “短句优先语音”接入 partner_chat_say 和 partner_chat_reply 的实际投递：delivery 默认 auto，开启偏好、渠道已配置通用 TTS 且正文为简短口语时，复用当前音色合成发送。delivery=text 保留文字选择；长文、链接、代码、图文混排和原文/详细交付保持文字。不改写人物台词，不在顶层新增语音工具。
- 前置语音确认送达后才放行承诺任务，最终语音确认后结束；继续接话仍留在本轮。真实语音子调用通过宿主权限、审批、取消和日志流程执行。
- 保留 TTS 的去重、输入变化、撤权与未知发送保护；未配置时 auto 使用文字，发送失败或未知不自动补同义文字。已确认语音在会话标注，父级投递不重复展示、不向渠道重发。

验证覆盖实际 ToolRuntime 嵌套调用、前置告知/工作/收尾顺序、文字例外、权限拒绝、新输入、撤权、未知发送与重复投递。

此次另行排查出上游 CLIProxyAPI v8.0.63 默认向聊天请求注入内置 image_generation，宿主不支持的响应可能表现为空正文。部署环境已将 multimedia.disable-image-generation 配为 passthrough，保留客户端显式工具与图片 API。此项是代理配置修正，不是伙伴包对模型接口的改写；历史记录保持原样。
