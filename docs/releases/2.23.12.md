# 2.23.12

修复工作期间插入追问导致表达阶段未触发的问题。此前只搜索最后一条用户消息之后的工作记录；用户在调查期间追问“你在做什么”，已完成结果在追问入列之前，最终文字因此直接使用原稿，且没有 workExpression 元数据。

改为读取当前回合的真实工作结果，同时保留最新追问与最初任务。不同轮次、不同渠道对象、混入内部任务或自主活动均不借用工作事实；生成过程中有新消息或权限变化仍停止旧回复。

表达输入将最新用户原话单独放在资料之后，区分当前追问与工作记录；先按当前问题选择需要回应的事实，再依用户原有人设表达。状态追问不自动变成技术报告，明确要求细节时保留相应细节。工具格式与事实约束放在人设资料之前，不添加固定角色台词、不修改用户人格卡或关系。

不修改滚动上下文、记忆和历史事件。普通聊天不增加表达调用。分段、表情顺序、原文保留、超时回退沿用原实现。

验证包括真实追问会话的同模型隔离回放及自动化回归。样本只能说明本次变化的效果，不能证明模型从此不再使用报告口吻；数字与链接检查仍不是完整的语义验证。未向 QQ 发送测试消息。
