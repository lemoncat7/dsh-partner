# 2.24.0-rc.4（测试部署）

任务前、中途接话和结果答复可共用只读表达入口：提交回应意图，并用当前轮真实工具调用 ID 引用结果。表达入口读取当前角色、关系设置及近期双方实际聊天，不继承完整工具目录，不执行工作、不写记忆、不改显示历史。人格内容仍全部来自可编辑设定。

- 保留直接文字回复；普通闲聊、指定原文、表达失败时均可直接成稿，不强制二次生成。
- 人格独占提示模式也支持表达入口；中途回复与最终回复使用同一套表达逻辑。
- 原有前置回应的送达等待、去重、待执行动作检查保持生效。已经送出的中途话不再重复投递。
- 引用拒绝跨轮、伪造和发言回执；发送前重新检查输入、人物、对象和授权。失败不结束当前回合，交回模型直接答复；不重跑任务。
- 明确无法继续的任务仍需通过 taskDisposition/taskEvidence 和直接 messages 说明原因，保留原有失败证据检查。

限制：表达入口是可选的一次额外模型调用，25 秒超时；本次隔离测试通常耗时约 4～5 秒。数字与链接有校验，但不是完整语义事实证明。32 次隔离对比未出现表达错误，语气改善有限，仍需实际对话观察，不宣称已解决所有人格偏移。
