# 2.11.2

DeepSeek 等模型在同一条助手消息中先输出文字、再只用 `partner_chat_reply` 提交图片时，插件现在会保留该工具调用旁的公开文字，再按顺序发送文字和表情。只匹配当前输入后的同一个终结工具调用，不提取推理、历史步骤或其他工具的进度说明；重复文字去重，原有权限和大小限制继续生效。

网页中的结构化回复现在投影为 DSH 原生 `assistant-step` 正文，复用原生 Markdown 与图片显示，移除了插件自己的气泡渲染器及样式。渠道仍按消息顺序发送，网页按原顺序展示各段及表情。没有改写会话日志、伪造助手事件或修改主题源码。

每轮增加简短的当前角色开场设定与聊天偏好提醒，把角色反应与发送协议区分开；不限制工作工具。DeepSeek 隔离试聊覆盖角色接话和实际任务的工具选择，不执行任何试验工具，也不向渠道发送测试消息。
