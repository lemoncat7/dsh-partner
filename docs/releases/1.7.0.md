## 兼容性
适配 DeepSeek Harness **0.1.2-rc.1**；Node.js ^22.19.0 或 >=24.0.0。正式版本，npm 标签 latest。

## 更新
- 新增可拖拽、弹性回摆和自由翻面的伙伴挂饰，顶部挂点可移动并保留位置。
- 伙伴回复、任务和定时执行的终态消息持久化；卡片内侧显示消息，正面保留图案，点击阅读并跳转来源。
- 新消息轻摆转正并短暂闪光，不自动弹出消息遮挡会话。
- 卡片设置支持开关、织带/编织绳/皮革、自定义颜色、正面图片，以及 24/30/60 FPS（默认 30）；设置仅保存在当前浏览器。
- 固定步长物理与绘制分离；静止/握持稳定后休眠，后台停止轮询与绘制，关闭时清理资源；无 WebGL 时提供普通消息入口。
- 渲染依赖内置独立同源资源；图片本机处理，不上传服务器。附第三方许可证。

## 验证
139 项测试通过；桌面、手机、横屏、深浅色、保存恢复、材质切换、帧率调度、拖拽回弹、消息提醒和资源清理完成核验。

## 从 README 迁入的历史说明

### 1.7.0 更新

- 主界面新增可拖拽、拉伸回弹和翻面的伙伴挂饰；拖动顶部挂点调整位置，适配窄屏并保留位置。
- 伙伴回复、看板与定时任务的终态消息汇入持久化消息收件箱。消息显示在卡片内侧，点击阅读并跳转来源；新消息轻摆转正、短暂闪光，不自动弹窗遮挡对话。
- 伙伴面板「定时任务」下方新增「卡片设置」：挂饰开关、三种绳子材质、自定义颜色、正面图片及 24/30/60 FPS（默认 30）。点击「保存设置」生效，仅保存在当前浏览器，不跨设备共享。
- 图片在本机裁切压缩，不上传服务器；支持 PNG/JPEG/WebP，最大 5 MB。绳子小样、预览和实际挂饰共用视觉逻辑。
- 绘制与固定步长物理计算分离；静止或拉住稳定后休眠，后台停止渲染和轮询，关闭时释放画布与物理场景。设备性能不足时实际帧率可能低于设定值；无 WebGL 时保留普通消息入口。
- 渲染依赖打入独立同源资源，无需另装 Three.js 或 Rapier；第三方许可见 [THIRD_PARTY_LICENSES.md](../../docs/THIRD_PARTY_LICENSES.md)。
