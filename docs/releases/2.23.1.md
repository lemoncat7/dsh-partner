# 2.23.1

修复 QQ 私聊和群聊输入只保留当前文字、漏掉引用内容的问题。保留结构化 reply ID，在已批准会话中通过 get_msg 读取原消息，核对同一私聊对象或群后，将引用文字与附件交给当前对话。引用标注为历史资料，不授予身份或工具权限。

每次只展开一层、正文最多 4000 字符、引用附件最多 4 个；总附件继续遵守 8 个/64 MB 限制。原消息不可用或不属于当前会话时明确标注；引用附件失效不丢弃当前问题。读取发生在各会话自己的处理队列中，有 5 秒读取超时，不阻塞其他会话轮询。网页可通过正常对话文字和附件看到新接收的引用，不重写历史、不自动重放旧消息。

兼容宿主 0.2.1-rc.5，保留 2.23.0 的表情收藏与递减自主活动。
