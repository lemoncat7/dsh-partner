# 2.23.11

工作后的最终聊天文字增加一次有条件的表达处理：主会话先完成调查并决定答复，只有本轮存在真实 `partner_work_execute` 结果时，才使用同一模型、原有人设和已核实的对象关系，结合最近对话及完整工作事实组织文字。表达阶段不加载看板、委派、部署或工具执行流程，也不执行工具。普通闲聊、自主活动、内部任务不增加这次调用。

不修改用户人格卡、原始历史、记忆或滚动上下文策略。工作报告保留事实、限制、证据与产物；模型选取与用户问题相关的信息。固定原文可使用 `preserveText=true`，代码块自动保留。表情 ID 与混排位置不变，最终文字继续使用原来的聊天元数据、分段和渠道投递链路，不添加自定义历史事件。

新增输入、人物关系变化、渠道撤权或取消时拒绝提交旧回复；输出不完整、未知工具、格式错误、新增数字或链接、超过资料大小限制及模型超时则保留主会话原稿。表达阶段最多等待 25 秒，真实模型样本通常增加数秒延迟。数字和资源校验不是语义事实证明；人格表达仍有模型波动，复杂技术答复仍可能偏长。

验证：完整自动化回归，线上同模型对最近视频调查的隔离回放，以及成功、失败、详细说明、原文保留场景。回放不实际发送 QQ 消息，不写生产记忆；成功/失败附加案例使用明确测试资料，不代表实际完成这些外部操作。兼容 DSH 0.2.1-rc.5。
