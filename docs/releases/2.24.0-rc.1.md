# 2.24.0-rc.1

B 站活动渠道预发布：未登录公开搜索、浏览、字幕及链接分享；扫码后按 API 开关开放互动。沿用渠道自主活动目录、人格及原有活动触发机制，增加提交去重与结果不明保护。设置页提供公开/登录能力分组、登录状态和执行记录。

见 [B 站渠道](../bilibili-channel.md)。本版需要独立连接服务，已验证公开接口及模拟写操作边界；真实登录和账号互动需在用户扫码后验证。

### 登录反馈与设置页修订

- 二维码由服务端持续检查并保存登录，关闭弹窗不再中断扫码确认。
- 显示待扫码、待确认、成功状态，以及账号昵称、头像、UID；支持手动刷新。
- 账号资料查询失败不撤销有效登录，退出或重扫会取消旧扫码任务。
- B 站设置使用独立紧凑布局，桌面双列 API，手机单列；移除接口代号及聊天渠道的错误说明。
- 修复 Web 扫码凭证只从回跳链接提取的问题：同时解析 Set-Cookie 与旧回跳参数；必须取得会话/CSRF 凭证且服务端验证有效后才保存并报登录成功。
- 修复字幕读取遗漏必需 cid 导致 ArgsException：先获取第一分 P 的 cid，再查询字幕；无字幕元数据时正常返回不可用。
