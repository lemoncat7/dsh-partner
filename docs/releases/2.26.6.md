# 2.26.6

支持 DSH 0.2.2-rc.1 / 0.2.2-rc.2，Node.js >=24.9.0。

- 伙伴挂载 MCP 改用独立 `partner_mcp` 入口，按服务分页发现、查询操作参数、用结构化 arguments 调用；不再与伙伴功能混排。原始操作补充 MCP schema 参数验证，保留宿主审批、取消及子调用日志，不公开未授权服务，不按名称隐藏其他插件工具。
- B站/QQ操作可经 `partner_tools describe` 同时指定 operation 查询，省去逐层目录；补充哔哩哔哩、QQ空间等别名及普通聊天平台检索指引。未支持或结果不足时保留通用网页检索。
- B站专用操作说明按需返回，活动目录按公开/登录分类；统一聊天投递和条件发言工具提示。保留原调用格式，人物设定和授权开关不变。
- 区分 MCP 目录查询与实际任务执行，目录查询不会提前结清任务；自主活动仅统计真实子调用，避免入口重复计数。
