# 2.24.0-rc.2 · B 站视频链接、投稿与渠道设置

- B 站设置采用与 QQ 一致的账号概览和分层导航：公开能力、私有能力、自主活动、执行记录。
- 私有能力总开关与自主活动独立，保留旧开关的有效授权；关闭自主活动仍可按明确请求执行已授权操作。
- 新增 video_stream，只返回临时视频播放直链、必要请求头及音视频分离信息；不下载、不合并、不抽帧。是否读取与如何处理由模型自身能力或可用工具决定，拿到链接不代表已经看过。
- 新增 upload_categories / upload_draft / upload_status / publish_video。当前会话内视频与封面可上传为本服务待投稿草稿；不是创作中心云草稿。正式提交单独授权，返回 BV 号仍需 B 站审核。
- 上传进度持久化；服务重启不重放投稿，结果不明不自动重发。素材只读当前会话目录，视频最多 512 MB，封面最多 8 MB，桥接暂存定期清理。
- QQ 非归属账号仅能调用 B 站公开接口，私有接口实时核验。
- 继承 rc.1 的扫码 Set-Cookie 凭证修复、后台登录确认和字幕 cid 修复。
