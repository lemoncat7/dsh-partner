# 2.8.1 · 挂坠光标主题兼容

兼容 DSH **0.2.0-rc.2**，Node.js **^22.19.0 或 >=24.0.0**。

- 移除挂坠抓取、拖动光标的强制优先级，允许主题通过普通 CSS 层叠覆盖。
- 调整光标选择器，保留卡片和挂点默认的 grab / grabbing 提示及禁用状态。
- 不修改拖拽、回弹、点击、指针捕获和会话数据处理逻辑。

验证：浏览器检查卡片与挂点的悬停、按下、松开、禁用状态，以及两种样式加载顺序下的主题覆盖；52 项挂坠测试通过。

对应：https://github.com/lemoncat7/dsh-partner/issues/2
