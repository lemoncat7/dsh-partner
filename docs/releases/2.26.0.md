# 2.26.0

- 渠道页的 TTS 分组改为「通用」，已有 TTS 配置与使用方式保持不变。
- 新增「浏览器」配置，通过 Chrome CDP 连接现有浏览器。支持连接测试、公开能力开关和自主活动开关。
- 新增公开 `partner_browser`，经伙伴统一入口的 activity 目录发现。提供标签页、网页读取、截图、点击、输入、按键、滚动和页面脚本；公开聊天无需私有能力授权。
- 支持 Docker 服务名连接，发现返回的 localhost 地址按配置目标连接；保留取消、超时、实时撤回、并发保护和未知结果不自动重试。

支持 **DSH 0.2.2-rc.1 / 0.2.2-rc.2**，Node.js **>=24.9.0**。操作说明见 [浏览器](../browser.md)。
