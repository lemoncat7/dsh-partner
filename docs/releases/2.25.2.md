# 2.25.2

支持 DeepSeek Harness **0.2.2-rc.1**，Node.js **24.9.0 及以上**。

- 修复生图任务前置回应因已知入口名称差异而失败：当 `image_gen.imagegen` 或 `generate_image` 未注册、另一个入口确实存在时，仅将动作登记规范为实际入口，并在工具回执中明确返回后续工具名称。不会替模型执行生图、创建不存在的能力或绕过权限；同时存在时保留所选入口。其他未知名称仍拒绝。
- 生图指导以当前工具列表为准，不再优先推荐可能不存在的入口；纠错信息区分伙伴目录与外部插件入口。任务前置检查改用当前的 `text` 参数，不再提示已移除的 `expression.intent`。
- 前置回应失败后的口头承诺不再视为任务完成：本轮可修正工具名继续执行，或明确说明未执行及原因。保留同轮有限恢复、成功动作不重做和未知发送不重复的限制；不会交给自主活动补做。
- 不将模型自述的“服务拒绝”视为生图错误，仍须提供真实调用和错误回执。该修复不改变生图插件、模型连接配置或已有会话历史。
