# 2.25.0-rc.1

支持宿主：DSH 0.2.2-rc.1。

- QQ 渠道新增独立「语音 TTS」模块，以分隔线区分其他设置。
- 支持 BreezeBlue、OpenAI 兼容 speech、自定义同步 HTTP（二进制或 JSON Base64）。服务可复用，渠道独立选择音色，保留 QQ 原生语音。
- 密钥存凭据库，不进入模型上下文；支持保存后本地试听。
- 公开 partner_voice_reply 工具按当前会话合成并发送 QQ 语音；旧语音调用兼容新服务。
- 区分合成、发送、确认状态，明确拒绝时复用音频，未知结果不自动重发；已确认语音计入本轮回复。
- 保留 rc.10/rc.11 的成稿投递、分段与短句接话修复。

验证：1,396 项完整测试通过；实际供应商仍需配置密钥和音色。当前渠道交付支持 QQ，暂不支持异步 HTTP 或音频下载 URL 响应。内部音频暂保留在数据目录。
