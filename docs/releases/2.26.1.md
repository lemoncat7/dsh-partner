# 2.26.1

支持 DSH 0.2.2-rc.1 / 0.2.2-rc.2，Node.js >=24.9.0。

- 修复自主群聊先旁听图片、后接文字时原图丢失的问题。同群同人 30 秒内的文字补充可补带最近图片；明确提图可回看两分钟内尚未提交的图片，最多四张。仅缓存短期引用，接话时才下载，不写长期记忆；新图或显式引用优先。
- 图片读取沿用渠道权限、来源与大小检查。补带下载限时八秒，失败保留当前文字并明确缺图；撤权及取消仍停止处理。
- 合并消息供接话判断时保留后续消息的附件，不再只看第一条有无图片。
- 保留发送前连续补充、首条送达后收束、任务防打断及其他群独立处理的规则。未改人物设定或模型。

最近慢回复中发现上游 500/TLS EOF、多次重试和流中断，并导致同群排队；本版图片修复不代表上游网络故障已经解决。

本轮追加：

- 接收 QQ 群文件上传通知；文件 ID 通过所属群/私聊的下载 API 解析，保留文件名、哈希和 busid，通知与对应文件消息共用回执避免重复处理。
- 视频缺少链接或媒体直链 403/404 时，通过核对所属会话的原消息刷新一次。下载仍受原媒体域名、授权、取消及 64 MB 总量限制，不读取桥接器本地文件路径。
- 先附件后说明同样支持文件和视频，最多补带四个近期附件；不会自动下载所有群文件。视频以附件保存，不虚称模型已经看过视频内容。
- 短句接话的普通分段改为每段所有中英文标点合计最多一个，保留半句至两句、可多段及特殊格式例外；不通过删标点拼成长句。
- 默认伙伴角色正文单独补充做事时的口语示例，仍保留十节结构。角色文本属于可编辑配置，不写入插件逻辑。
