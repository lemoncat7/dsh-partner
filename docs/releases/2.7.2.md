# 2.7.2 · 任务清理与功能页响应优化

正式补丁版本，适配并验证 **DSH 0.1.7-rc.2**。Node.js **^22.19.0 或 >=24.0.0**。

- 看板受阻任务继续采用安全恢复语义：暂时性执行故障进入自动重试；需要重新规划的任务不会原样循环执行，解决权限、工具或分工问题后可由负责人恢复。
- 已完成或取消的一次性续接不再占用计划列表。独立任务在最终回复可靠送达后删除持久记录；看板任务在恢复执行消费完结果后删除，避免丢失通知或误判任务中断。
- 伙伴能力页不再预取三份资源目录；Skill 市场的本地安装列表、远程市场和网络设置独立加载，远程来源缓慢或失败不再阻塞本地内容。
- 设置页“升级迁移”区域压缩段落、详情和路径卡片留白，保留 44px 操作区域与完整说明文字。

Node 24 完成 622 项全量测试；其中 619 项在高并发全量运行中直接通过，3 项既有等待时序用例在资源竞争下超时，隔离重跑均通过。新增的一次性清理、续接可靠投递、请求解耦和紧凑布局测试全部通过。

本版本不改变存储 schema。升级前仍建议备份插件数据目录；可回退到 2.7.1，尚未安全消费的续接记录会继续保留。
