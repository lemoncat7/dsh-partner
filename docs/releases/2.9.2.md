# 2.9.2

身份与人格设置改为分段编辑，避免将全部能力和内容铺在同一页。

- 基本身份与人格强化分开；人格内容按角色核心、说话方式、世界与关系、预览试聊、角色记忆展示。
- 对话示例、世界条目按需展开；新增空条目保持展开，输入时不自动收起。首次创建仍使用分步弹窗，示例保持通用。
- 切换分段保留草稿和试聊历史；后台配置刷新不会覆盖未保存的身份编辑，保存保留最新模型和能力配置。
- 记忆设置按学习、每日终审、上下文焕新分段。模型选择折叠在学习设置内，焕新在记忆关闭时仍可独立配置。
- 自然聊天行为独立维护，对话示例新增可选反例；旧人格卡兼容，工作及心跳协议不变。不增加额外模型调用或回复延迟。

本次不新增 QQ 渠道，尚未启用多气泡发送、连续输入合并或工具驱动发送。调研与后续落点见 `docs/natural-conversation-port.md`。
