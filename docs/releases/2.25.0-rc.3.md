# 2.25.0-rc.3

支持 DSH 0.2.2-rc.1。

- 自主活动记录直接展示时间线、最近保留记录的分类统计、发送确认及操作失败状态；分页查看详情，念头单独折叠。
- 根据真实聊天/附件回执和持久化分片确认判断发送，不再用安静结束推断整轮未发送；历史缺少回执不伪报成功。近期原始记录可渐进补齐。
- 编辑文件也记录作品路径，关联同路径的多轮进展，支持复制路径。当前保留最近 40 轮，不是永久档案；不扩大注入模型的历史条数。
- 新作品、实质进展和新见闻可按人格自然分享；减少重复的沉默提示，不强制消息频率或固定语气。指导具体后续意愿通过现有 plan/focus 安排，同主题念头复用和收尾。
- 活动页面按需加载，不增大主界面首包。

验证：完整回归及生产页面验收见部署记录。行为效果仍需后续真实活动观察，不承诺固定分享次数。
