# 2.25.1

支持 DeepSeek Harness **0.2.2-rc.1**，Node.js **24.9.0 及以上**。

- 普通对话直接在当前会话调查和执行工具，不再提供独立工作入口；明确后台、定时、看板与委派任务保留原入口。人物自行撰写开场、中途与最终回复，不再调用第二个模型重写普通聊天。保留分段、任务前回执、动作核验和附件交付。
- 角色聊天 → 聊天方式 → 短句接话增加“短句优先语音，长句用文字”，默认关闭。启用后作为发送偏好注入，也适用于独占人格提示模式；使用当前已配置并授权的语音，明确请求优先，链接、代码和长解释仍适合文字。具体选择由模型决定，不自动复制发送文字。
- 修复自主念头 list 的非无损 JSON 返回；同会话立即 focus 留在本轮推进，settle 更新状态后继续活动。跨会话或延后的 focus 仍安排后续，不跨对象泄露资料。
- 自主活动可根据已授权的 B 站、QQ 空间等能力浏览、互动和分享，不以用户新问题或完成新作品作为前提；自然接话可以在同一轮继续，有具体后续意图时才安排下一轮，不强制发帖或发言次数。
- 自主活动支持中途文字和表情，沿用渠道发送回执与权限检查。决定休息时可以先按人物告别，确认送达再睡眠并安静结束；只放在自主活动中，不添加到普通聊天或定时睡眠检查。新输入、取消和授权变化阻止旧消息，已发送的中途消息不在最终收尾重复发送。

旧会话、工作报告与展示记录保留兼容，不修改历史。新增语音偏好和自主表达仍受模型选择影响，不承诺每次使用语音或发布动态。
