# 2.23.14

工作回复只读取本轮所选事实、未解决事项、需要交付的位置、最近提问及已确认的前置消息/语音和休息记录。旧助手报告与主会话的回应目的不再充当回复提纲。普通 `messages` 仍由主会话直接撰写，不增加自动改写。

用户配置的篇幅和动作描写选项，在每次主会话与工作回复请求中各自提供一次；人格正文与聊天语气仍留在系统身份中。简短选项说明当前问题的回答范围，避免自动补齐过程、总结或备选菜单；明确要求步骤和细节时展开。没有新增固定角色、口头禅、情绪、强制玩笑或字符截断。试聊及规则预览沿用相同选项。

事实引用区分结论、证据与交付物，避免把内部临时文件误选为必须交付的附件。未解决事项仍完整保留，引用与当前回合、回复对象、授权绑定。

新增受限的同日时刻差核算：模型引用所选记录里的原始时刻，由程序计算分钟数和小时/分钟；来源不明、跨工作记录、跨日或时区含糊时拒绝推算。数字和链接校验仍只是局部校验，不等同于完整语义证明。

以上均为请求组装和既有工作回复工具的调整，不改写历史事件、记忆、角色卡、关系、模型配置或滚动窗口策略。运行期间的输入、身份、休息与授权变化仍会阻止旧回复；生成失败仍交还原会话处理。
