# 2.8.4-style.1（本地体验版）

适配 DeepSeek Harness 0.2.0-rc.2，沿用知识库 2.13.12 的交互风格。

- 统一按钮、表单、页签选中态、能力卡片及提示层的交互样式。
- 公共弹窗采用居中圆角外框与内嵌内容区，根据屏幕和内容自适应；长内容内部滚动，窄屏不强制铺满。
- Bark 未保存修改使用统一确认弹窗，默认聚焦“继续编辑”，保留原编辑器及草稿。
- 保留身份与渠道表单对主题覆盖的隔离，支持深浅色、可见键盘焦点与减少动态效果。
- 本次部署与已安装包相比仅更换前端产物，不改变关注、看板、通知执行或挂坠渲染逻辑。

浏览器回归脚本：`check-workspace-dialog.mjs`、`verify-form-surface.mjs`、`verify-bark-channels.mjs`、`verify-memory-workspace.mjs`、`verify-workspace-navigation.mjs`。宿主 UI 测试依赖可通过 `DSH_UI_TEST_NODE_PATH` 指定独立目录（冒号分隔）。
