## 兼容性

正式版，适配 DeepSeek Harness **0.1.2-rc.1**；Node.js ^22.19.0 || >=24.0.0。知识库挂载管理需搭配 **dsh-knowledge 2.4.0+**。

## 更新

- 伙伴身份、能力、Skill 和协作配置保存后，在下一轮执行前统一注册；覆盖已有浏览器会话和历史会话恢复，不在运行中的轮次重组工具，不唤醒闲置会话。高权限工具调用时仍检查当前授权。
- 「应用能力组合」增加保存中、成功、失败反馈；成功显示「已保存，下一轮生效」，防止重复提交，失败保留草稿，并区分保存失败与后续刷新失败。
- 新消息轻摆转向文字面，仅在文字面扫光两次；结束或阅读后不自动恢复图案面，手动拖拽和翻面仍自由。
- 挂点旁保留静态小数字未读标记，超过 99 显示 99+，全部已读后隐藏；支持深浅色与减少动态效果，不增加常驻渲染循环或自动弹窗。
- 保留卡片材质、自定义图案、24/30/60 FPS 和静止休眠策略，不改 DSH 源码或伙伴数据。

## 验证

162 项自动化测试通过；浏览器验证真实拖拽、回弹、文字面停留、已读行为、未读数字、休眠、移动端、深浅色及减少动态效果。能力保存交互覆盖 6 组响应式与主题场景。

本机已部署同一个本地构建包，逐文件和 SHA-512 校验一致；服务健康，3080 API 与 3081 门禁检查通过。
