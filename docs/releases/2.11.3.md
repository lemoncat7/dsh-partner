# 2.11.3

分段开关改为“允许分段回复”：默认一条自然回应，删掉“优先分成两条”与“先顶嘴再补真实想法”等会诱导固定套路的规则。保留按需分段、纯表情和完整工作交付，不限制工具。

角色设定新增“大肥鱼参考”弹窗：说明 qq-bridge 小鲸鱼的身份、说话习惯、节奏、正反例结构，附对应提交的完整只读原文及来源链接。通用向导示例继续通用，现有角色内容不被覆盖。背景条目的勾选框和文字采用 12 px 间距及至少 44 px 高的点击区域。

表情库说明原项目取图自登录 QQ 账号收藏，而非随仓库发行的公开图片包。新增批量导入本地收藏图片，支持可选的 qq-bridge `state/stickers.json` 资料匹配：图片文件名与 ID / MD5 相同则带入名称、标签，未匹配则使用文件名。预览匹配结果，逐张报告失败；导入不访问 JSON 中的 URL，不登录 QQ。沿用现有图片格式、大小、容量与伙伴隔离校验。

补齐 2.11.2 的生产主题验收：原生 Markdown 只把绝对 HTTP(S) 地址识别为网络图片，伙伴现在用当前网页的 baseURI 解析表情 URL，避免将 `/partner-local` 当成本地文件。日志仍保留相对地址，切换访问域名后照常显示。网页验证要求真实图片元素存在并成功解码，不能仅凭没有报错判定通过。

工具参数已经含有文字时，以该最终正文为准，不再拼入工具调用旁的近义前言。只有工具参数完全没有文字时，才补入同一次终结调用旁的公开文字，修复 DeepSeek 只投递图片的问题并避免复述。
