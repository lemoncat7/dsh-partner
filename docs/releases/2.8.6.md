# 伙伴 2.8.6

## 宿主兼容

本版本支持 **DeepSeek Harness 0.2.1-rc.2**，包含 2.8.5 的宿主适配。仍在 DSH 0.2.0-rc.2 的用户请使用 2.8.4，不要强制安装本版本。2.8.5 的 Git 标签保留，但 npm 发布未完成，本版本为后续完整发布。

## 更新

- 新增可选内置 Skill「AI 镜头语言与运镜」：完整保留 32 项词典、视频总结与时间索引、故事转分镜、双语提示词及失败修订示例。参考资料按需读取，无需联网下载资源；安装后在伙伴能力中授权使用，不自动给全部伙伴启用。
- 精简安装包：不再分发小说改编游戏 Skill 的上游示例游戏成品和大图片。全部七个技能模块、参考资料、来源和许可证保留；卡牌渲染和伙伴业务功能不删减。压缩包从约 19.2 MB 降至约 7.5 MB。
- 同步调整离线导入过滤规则与安装资源清单，避免资源缺失校验失败或下次导入再次膨胀。已安装内置游戏技能升级时清理其旧示例资源，保留伙伴授权；不清理用户项目产物。
- 新增实际发布包检查：核对内置目录与目录注册、逐文件哈希、必需运行文件及包体积。

## 验证与安装

已完成构建、747 项自动测试和实际 tarball 解包资源校验，覆盖新 Skill 安装/授权/取消授权、损坏修复、卸载以及旧游戏技能升级。不代表已对真实视频模型完成效果评测；未发送真实渠道测试消息或执行收费生成。

安装：`dsh plugin --profile web add @lemoncat7/dsh-partner@2.8.6`。

安装前备份配置与插件数据；安装后重启实际使用的 Profile。桌面端使用对应 Profile。没有修改 DSH 核心或主题，不迁移、清理生产会话数据。

参见 [宿主兼容说明](../dsh-021-compatibility.md)、[内置影视技能](../director-skills.md) 与 [安装包资源范围](../package-distribution.md)。
