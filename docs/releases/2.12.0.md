# 2.12.0 — 自主睡眠与梦境

身份新增“睡眠与做梦”。角色可在聊天中调用 `partner_sleep` 自主选择休息 5–720 分钟，不设固定睡眠时间；后台也会在空闲时低频判断是否想休息，模型可以选择继续清醒。

- 已启用角色聊天的旧身份默认开启睡眠与做梦，工作型身份默认关闭；用户可单独修改开关。设置遵守人工草稿/生效身份的分离规则。
- 睡眠只暂停闲时主动搭话，不限制工具、任务、定时交付或直接回复。真实用户消息唤醒；时长结束自然醒；页面也可叫醒。未完成的排队/执行任务会阻止入睡。
- 移除身份里的固定免打扰时段，旧时段不再控制闲时联系。没有每日联系次数上限，未回复不连续追发的规则保持。
- 梦境仅从本会话已有的有效记忆产生虚构联想和主观感受。独立存储最近 12 个梦，不写入事实记忆、不执行每日终审、不触发上下文焕新、不自动发送梦境报告。记忆关闭或没有可用记忆时只休息。
- 梦境按会话隔离；共享同一个真实会话的渠道可共享梦境。聊天只提供近期一个梦作为非事实参考，并要求谈到时明确是梦或联想。睡眠与梦境在重启后保留。
- 用户叫醒或修改人格时，过期的后台结果不再写入。截断/断流不是成功；失败不会无限重试。

后台每分钟检查状态，一次最多发起一个模型请求。只有空闲至少 15 分钟、最近两天有活动且没有执行任务的角色才会进入自主判断；同一段活动只判断一次，两次判断至少间隔一小时。这是控制后台开销的检查节奏，不是强制入睡时间。梦境使用当前伙伴模型，最多生成一次；记忆整理流程继续独立运行。

验证包含自主判断、消息/手动唤醒、自然醒、并发失效、重启恢复、会话隔离、独立存储及闲时发送拦截；页面验证使用拦截保存与模拟状态，不向正式渠道发送测试消息。
