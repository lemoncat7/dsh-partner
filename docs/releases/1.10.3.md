# 1.10.3

正式版，兼容 DSH v0.1.2-rc.1；Node.js ^22.19.0 或 >=24.0.0。

- 修复创建子任务或后台进度变化后，需求操作反复提示“需求内容已更新”的问题。
- 普通需求操作允许兼容自读取以来的子任务新增、执行进度和评论；需求范围、负责人、子任务规格、删除与生命周期调整继续受并发校验保护。
- 保留完整版本对最终归档、汇总取消和渠道投递的校验；任务验收仍必须基于实际核对的版本，不自动重交旧验收意见。
- 真实冲突返回最新需求内容、状态、版本和明确的恢复建议；创建任务的响应附带父需求版本。不以盲目重试或重复建需求规避冲突。
- 旧数据按现有版本保守初始化，版本边界持久化，服务重启后继续生效；不清理、合并或重建现有任务。
- 不修改 DSH 源码、界面样式或拆解 Skill，不增加轮询和后台作业。

验证：构建及 241 项自动化测试通过，包含连续创建、并发修改、旧记录重启、过期验收、汇总取消与通知重试。
