# 2.15.0 · QQ 会话选择与渠道表情适配

新增「会话与记忆」：默认每个群、每位私聊用户使用独立会话，以群名/联系人名命名；勾选指定用户或群才接入主会话。取消勾选接回原独立会话，原始记录保留。所有会话沿用该伙伴长期记忆，升级合并旧群记忆但不拼接聊天原文。群消息保留发言人来源，群内交付仍返回来源群。

新增「自主回复白名单」：指定群不必 @，无工具的模型先判断接话时机，需要时再交给伙伴回复。普通成员消息作为背景，已授权成员才能触发操作；无效判断、超时和繁忙时保持安静。保留明确 @ 回复方式，不限制伙伴正常回复时的工具。

表情工具新增渠道适配层：默认库保持兼容，QQ 默认优先系统表情及收藏表情包，支持浏览、查看和原生发送，目录不可用可回退默认库。原生表情与文字保持原顺序；发送未确认时不会重复补发图片。

修正未保存提示的白底及表单、开关、底部按钮对齐，提示背景随当前主题。
