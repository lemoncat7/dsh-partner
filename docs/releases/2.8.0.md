# 2.8.0 · 关注生命周期、受阻协调与负责人交付

支持并验证 DSH **0.2.0-rc.2**，Node.js **^22.19.0 或 >=24.0.0**。不声明兼容未经验证的旧版宿主。

- 持续关注新增查询、修改、解决、停止和删除工具；保留伙伴隔离和并发版本检查。
- 收紧一次性工作误建关注的判断，后台任务不能借用历史用户指令创建关注。
- 受阻任务先交创建者处理，再升级需求负责人；持久化协调进度、有限重试，确需用户介入才统一汇报。
- 临时计划绑定看板任务，完成或删除后清理；不提前删除未送达结果，不盲删没有关联信息的历史周期任务。
- 负责人明确提交总结与正式附件清单；渠道不再自动收集全部附件或额外生成总结文档。
- 同一需求、同一接收人的相同内容附件跨阶段、归档和重启去重，失败只补发未完成部分。远端确认丢失仍存在重发边界。
- 修复“需求成果交付”回执误切断正常答复收集，导致页面有回复、渠道报空的问题。

验证：646 项自动化测试通过；真实会话回放确认空答复修复；本地构建已部署检查。既有任务与记忆数据保留。
