# 2.22.0

插件版本 **2.22.0**，目标部署宿主 **DSH 0.2.1-rc.5**；依赖范围不变。

在「记忆设置 → 对话窗口」增加滚动对话上下文开关，默认关闭。开启后保留最近 20 轮，并以 48000 字符预算优先移出旧完整轮次；可调整为 2–100 轮、4000–200000 字符。当前未完成轮次、系统消息和工具定义保留，不调用模型生成摘要。原文保留在会话日志，可按需回忆。开启期间暂停每日整段焕新，学习和每日终审独立运行。

partner_memory_recall 作为公开基础工具直接展示，所有聊天账号均可发现和调用，不依赖长期记忆学习开关或归属账号。除现有长期记忆和归档检索外，增加当前会话窗口外的原始对话检索；不同渠道的记录按真实来源隔离。私聊先按当前人格自然说明准备回想什么，再检索并继续处理。

包含 2.21.14 的私聊任务交接、前置回应和最终文字投递修复。细节与边界见[滚动对话说明](../rolling-conversation.md)。
