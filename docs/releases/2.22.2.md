# 2.22.2 — 历史加载兼容性修复

消息来源元数据改用宿主的 appendPluginRecord 接口，事件类型为 plugin:dsh-partner/input-origin，自动带有 ignorable: true，避免重启后持久化加载器拒绝整条会话。来源数据继续用于回忆时区分联系人，不参与模型消息或页面聊天内容。

滚动继续使用原生有效上下文 surface replacement；页面历史仍读取完整事件日志。保留 2.22.1 的过期运行时快照清理，不拦截模型请求，不覆盖宿主压缩方法。新增宿主持久化校验回归测试。

部署时对受影响日志先完整备份，仅修复来源元数据的类型和兼容标记，保持原始聊天、事件序号、时间和 payload 不变。宿主保持 0.2.1-rc.5。
