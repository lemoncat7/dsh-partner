# 2.19.2

降低 QQ 收发链路的本地等待：OneBot 的文字、图片等消息段已在同一个事件内，直接交接处理，不再等待一秒拼接窗口或每轮轮询后的一秒休眠。Matrix 附件拼接保持原行为。

QQ 按真实聊天目标分别准备输入；一个群的接话判断不会阻塞另一个群或私聊的准备。同一聊天仍按顺序处理，整条渠道共用 100 组积压上限。同一伙伴的模型执行继续串行，不并发改写共享上下文。

状态未改变时跳过磁盘提交与变更通知；收到消息时将最近联系时间和防重收据合并为一次持久化。实际修改仍校验、原子写入并同步到磁盘，发送前的账号、好友、群成员、审批和归属权限校验保持有效。

新增不包含消息正文或令牌的 `[qq-latency]` 分段日志：WS 到处理队列、接口验证、模型输入准备、模型回合、回合后处理及发送耗时。日志用于区分本地排队、磁盘处理与模型等待，不承诺固定回复时间。
