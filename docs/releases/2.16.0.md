# 2.16.0

- QQ 自主接话不再被整个伙伴的忙碌状态提前丢弃。已授权发言正常交给判断模型，需要接话时由现有会话队列处理；未授权成员、冷却和模型判断保持原有规则。
- 渠道面板显示当前任务来源：后台记忆、回合归档、会话准备或具体运行会话。
- 修复角色记忆超过 20 条剧情事件导致后台整理持续重试。自动生成的摘要去重并保留近期条目，完整对话仍在日志中，手动编辑限制与固定记忆保护不变。
- 新增 `partner_qq` 工具，以 list / describe / call 发现并调用 89 项经过筛选的 SnowLuma 能力，按空间、语音、互动、消息记录、资料、群资料、公告、管理、文件和相册分组。
- 自主能力总开关和每项操作独立配置，旧渠道默认关闭；语音可选 QQ AI 音色，空间发布默认好友可见。配置位于渠道 → QQ 设置 → 自主能力。
- 私聊与群操作受已有授权、群白名单和渠道开关约束；消息 ID 操作先验证来源会话；跨伙伴调用、未列出的接口和凭据接口不可用。群成员管理由所选群与单项管理权限授权。
- 媒体来自伙伴工作目录内普通非隐藏文件，单文件 16 MB、每次最多 9 个、总计 32 MB；读取实际文件后以 base64 传输，不将工作目录路径交给 QQ 容器。
- 对外操作先持久化调用标识；断线或超时结果不明时保留记录并禁止相同调用自动重发。确认记录保留 30 天，未确认记录持续保留；页面显示最近 20 条。此机制不替代跨调用业务去重。

QQ AI 文字转语音是群能力；私聊支持已有音频文件。操作是否可用还取决于 SnowLuma 版本、QQ 账号和群权限、网络及平台限制。未进行真实发帖、评论、语音或管理操作测试。

本次环境排障还修正了 SnowLuma 容器继承的失效 Tailscale DNS：Compose 固定 `223.5.5.5` 与 `119.29.29.29`，当前容器同步应用；保持 `appnet`。修正后在线只读检查确认 QQ 空间说说列表、好友动态和 30 个 AI 音色均可读取。

AI 仅注册一个 `partner_qq` 入口。`list` 默认返回已开启的分类与数量，带 `category` / `query` 时最多返回 20 项操作概要（`offset` 翻页），`describe` 才返回单项参数。完整 89 项 API schema 不进入每轮工具定义。

伙伴「能力组合」新增可选的「按需加载伙伴工具」。开启后只常驻目录入口与聊天回复/表情，工作工具按分类发现，再 load 原工具；最多保留 4 项最近加载的工作工具。仍通过 DSH 原工具注册与执行流程运行，保留审批、能力撤回、超时、取消、输出和终结回合语义。旧伙伴未设置开关时保持原工具展示；本次先为莫殇开启。原生宿主、SSH/知识库等独立插件工具不由此功能收缩。
