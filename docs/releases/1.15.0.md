# 1.15.0

伙伴插件正式版。已部署验证的宿主为 **DSH 0.1.5-rc.1**（宿主仍为 RC），要求 Node.js **^22.19.0 或 >=24.0.0**。保留旧宿主兼容分支，但本次未重新完成全部旧宿主端到端验证。

## 新增与修复

- 新增 Matrix、Mattermost 文本私聊渠道，保留微信。支持账号密码与 Access Token；Mattermost 支持 MFA 验证码。
- 房间 / DM ID 可选；默认自动发现私聊，发送配对码，面板批准后才调用伙伴。Matrix 仅支持未加密双人房间，群聊、E2EE 和新增渠道附件暂不支持。
- 同一伙伴本地及所有已授权渠道共用主对话；回复回本次消息来源，通知可指定目标，否则跟随最近入站渠道。不同伙伴仍隔离。
- 测试成功后的登录令牌在服务端内存暂存 5 分钟，重复测试与保存复用，未保存的令牌到期尝试退出。429 显示等待时间并抑制重复认证。
- 渠道与配对状态每约 3 秒轻量刷新，打开的弹窗同步更新；每渠道一行，统一配置弹窗，修复字段与授权按钮挤压。
- 修复单项关注失败造成其他关注通知被阻塞的问题，失败项单独退避。

## 升级注意

**共享主对话是行为变化：所有获准联系人可共享该伙伴的上下文。仅授权可信联系人，不要用于需要按用户隐私隔离的公共机器人。** 已有本地主对话优先，没有本地主对话时继续最新可用渠道对话；不拼接或删除旧历史。不自动扩大伙伴工具权限。

升级前备份状态与凭据；配置新渠道后不要直接降级到仅识别微信的版本。

验证：372 项自动化测试通过；生产浏览器检查通过（状态轮询、配置入口、登录方式切换、弹窗及手机布局）。真实外部账号所有收发场景尚未完成端到端验收；Mattermost 使用约 10 秒 REST 轮询。

## 1.15.0 更新：多渠道与共用主对话

插件正式版，运行验证环境为 **DSH 0.1.5-rc.1**，Node.js **^22.19.0 或 >=24.0.0**。DSH 宿主自身仍是 RC；旧版兼容分支保留，未重新完成全部旧宿主端到端验证。

- Matrix / Mattermost 账号密码或 Token 登录，房间 ID 可选，通过私聊配对并审批。
- 同一伙伴本地与所有渠道复用主对话，通知可指定目标或跟随最近渠道。
- 连接状态、配对请求自动刷新；复用统一配置弹窗，修复重复登录触发限流及错误提示。
- 单项关注受阻不再阻塞其他关注。

升级前备份数据；共享上下文是本版行为变化。详见 [1.15.0 发布说明](../../docs/releases/1.15.0.md) 与 [渠道使用说明](../../docs/direct-channels.md)。
