# 2.24.0-rc.5

独立工作增加实时进度卡，解决主会话长时间只显示一个 partner_work_execute、无法判断内部是否仍在推进的问题。

- 展示等待启动、等待模型继续、正在调用的工具、已结束操作数量、目录查询数、失败数及最近五次操作；不显示思考、参数、结果正文或私密查询。
- 显示累计耗时；超过30秒没有状态变化时显示距上次变化的时间，不把“仍在等待”误报为卡死，也不使用虚假完成百分比。
- 完成、部分完成、失败、取消和超时有不同状态；工作结束不代表聊天或附件已经交付。
- 同一调用只更新一张卡片；支持历史恢复、窄屏和键盘展开最近操作。回合已关闭时停止旧卡片的运行状态。
- 使用 DSH 官方 appendPluginRecord 写入 ignorable 展示记录，不添加模型消息，不改变滚动上下文、已有聊天历史或任务执行权限；展示故障不阻断工作。

本版只改善执行可见性，不改变任务15分钟时限、自动重试策略或任务执行速度。旧任务没有进度记录，无法补造其过程。
