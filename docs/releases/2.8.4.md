# 2.8.4 · 统一交互、Bark 通知与持续关注可靠性

适配 DeepSeek Harness **0.2.0-rc.2**；需要 Node.js **^22.19.0 或 >=24.0.0**。不改变现有宿主版本约束。

## 界面与保存

- 统一按钮、输入框、搜索和下拉控件；弹窗居中、自适应视口，浅深主题保持一致，防止宿主主题覆盖身份和渠道控件。
- 运行配置改为紧凑摘要与选择弹窗，模型支持搜索，不再用三条长下拉框占据能力页。
- 自动保存弹窗不再显示多余的“完成”；保留保存中、成功及失败反馈。手动保存按实际内容差异判断草稿，展开高级选项、查看下拉框或改回原值不触发放弃确认。
- 固定底部与正文使用同一背景，避免色差和滚动文字透出；失败保留编辑内容，确认弹窗保持焦点及原草稿。

## Bark 与持续关注

- 在渠道中增加 Bark，支持多个服务器和发送目标；无需联系人配对，独立于双向渠道的通知交付选择。Key 存入凭据服务，不回显。
- 最终结果异步入队，按设备记录、退避重试及重启恢复；可查看、重试或清理投递记录。不逐条推送工具和验收过程。服务端接受不是设备送达回执，网络回执丢失时仍可能重复通知。
- 持续关注按“读取依据、识别步骤、核验证据、交接执行”推进，支持定向知识文档／笔记分页读取、版本复核、批量登记步骤及恢复检查点。
- 开启后续执行时直接向伙伴原会话交接核实结果与步骤，不另建看板；区分检查与执行，不把待成稿、待生成步骤误报为检查失败。
- 为读取依据和登记检查点提供有界准备预算；临时模型连接错误有限退避重试，不重放已经执行的工具操作。修正自动压缩检查点导致的执行回执误判。

## 看板临时 SSH 授权

- 搭配 SSH 插件 **1.11.3**，按具体看板任务、指定执行伙伴和实际执行会话绑定临时授权，不共享创建者的永久挂载。
- 暂不启动任务，核验真实用户授意后再提交执行；一次执行有效，结束、取消、过期、改派或任务要求变更后不可复用，重试与验收不自动继承。
- 无 SSH 插件或没有相应授权时维持原权限边界，不自动启用能力。

## 验证与升级

- 744 项测试通过；浏览器回归覆盖能力自动保存、Bark 编辑及放弃确认、弹窗焦点、主题覆盖、记忆工作区和窄屏布局。
- 功能代码与已部署的 `2.8.4-style.4` 试用版一致；与 SSH 的授权联动已通过隔离模拟验证，未在测试中执行真实远端命令。
- 沿用既有存储布局，新增 Bark 状态字段向后读取兼容，无须执行存储目录迁移。升级前仍应备份配置与凭据；升级并重启 Profile 后刷新页面。
- 不自动重放旧发布任务或受阻任务，不承诺上游模型、渠道和外部服务始终可用。
