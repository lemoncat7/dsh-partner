# 2.28.1

- QQ 群聊可在不选群时直接训练默认分类头、角色和关系设定。选群训练时提高历史取样上限，结合群内前文和引用识别场景，按类别展示训练及留出样本。已有群分类头和共同版本可以继续使用。
- 群友都可以用角色设定或关系设定中已学到的称呼呼唤伙伴。关系正文和关系场景按已核验的绑定账号生效。识别会区分直接呼唤、转述和明确回复其他成员。
- 内置场景分类头增加追问、接梗、分享、抛话题、收尾等样本。在同一组 72 条验证样本上，判对数从 51 条提高到 56 条。
- 设置问答和训练标注沿用对应会话的模型与推理配置，取消插件固定的输出额度。多群历史按各群对应会话选择标注模型。
- 后台任务通过宿主的 Agent 接口创建和恢复，插件负责工具准备、交付清单和会话回收。已有后台会话可以按原 ID 续做。旧版留下的宿主子会话目录项可能仍显示在页面中。
- 持续关注在伙伴主会话处理，并沿用配置的通知渠道。

升级后重启对应的 DSH Profile。群分类头按原配置加载。需要增加历史训练样本或刷新设定特征时，可从 QQ 自主回复设置重新训练。详见[群聊本地识别](../qq-attention.md)与[宿主兼容策略](../host-compatibility-policy.md)。

全量测试覆盖 QQ 训练、后台任务恢复及关注通知。另在现有部署中回放了群友称呼，在隔离会话里验证了默认模型训练、群模型留出评估和现有群分类头保留。
