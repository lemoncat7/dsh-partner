# 2.25.5

支持 DSH 0.2.2-rc.1。

- 自主活动改为清晰的「最近活动 / 惦记的事」切换；设置前置，活动摘要、作品与执行依据按需展开，旧念头独立折叠。使用不透明主题面板，适配窄屏与键盘操作。
- 每位伙伴所有会话合计最多保留 12 条活跃念头。提取、工具新增、重新关注与存储提交统一限制；优先保留执行中、已安排与较新、较少反复考虑的念头。
- 现有超额念头自动标为「容量整理 · 已放下」，不冒充已完成，保留原文和进展；当前与旧念头总计继续有界保留 64 条。载入迁移写回，重启后保持一致，不修改聊天历史、人物或关系设定。
- 保留 2.25.4 的送达回执与自主检索修复、2.25.3 的短句语音行为。

- 短句节奏明确限制每条而非整轮：允许当前轮自然补话。自动语音逐条保留 messages 的消息边界，不再拼接多条短句；新输入、撤权或未知发送停止剩余投递，已确认内容不重复补发。人物正文保持原配置。
