# 2.26.3

支持 DSH 0.2.2-rc.1 / 0.2.2-rc.2，Node.js >=24.9.0。

- 群聊搭话判断增加最近 90 秒内最多四条背景（含伙伴最近已送达回复），用本地句向量的语义关联辅助判断；当前消息意图独立分类，不将历史呼唤当成新指令。
- 放宽明确交流倾向的准入，结合上下文接纳部分短句承接；群友互聊中可选插话概率从 45% 调到 65%，只决定进入回复流程，不强制发消息。
- 同群非定向主动插话间隔从 20 秒缩为 5 秒；@、明确呼唤及已建立的同人对话不受此间隔影响。
- 保留明确转向他人、结束对话、睡眠、任务防打断及首条送达后的群噪声保护。分类超时仍有界，背景只在本地短期缓存，不写入长期记忆。
- 本地识别服务协议 v2 与旧单句调用兼容；旧服务仍可使用当前句分类及新门槛，不提供背景关联分数。
