# 2.23.0

- 新增 QQ「收藏表情」能力分类：读取收藏详情、收藏工作目录图片、修改情绪备注、调整顺序和删除明确不需要的表情。操作受既有账号归属、能力开关和调用去重约束；图片限制 2 MB，收藏前按 MD5 检查前 200 项中的重复。操作后立即使表情目录缓存失效。
- 当前授权渠道可由 AI 自主挑选表情并整理收藏；其他渠道的新能力默认关闭。日常聊天更积极使用符合人格的表情，不强制每轮发，不发送整理汇报。
- 回复后自主活动概率由 5%–45% 提高到 45%–80%，好感度关闭仍有 45% 基础概率。实际活动完成后逐轮减半，活动链最多 5 轮。空闲活动也可启动递减延续；不行动则停止，完成了工具活动后安静结束仍可继续。
- 概率结果和链深度持久保存；新输入、睡眠、权限撤销、中断和过期均阻止旧链继续。上一轮渠道消息尚未完成投递时不启动后续活动。沿用现有计时器和每轮工具预算，不新增后台自循环任务。
- 保留完整人格、聊天历史和睡眠恢复每小时 35 点。宿主兼容 0.2.1-rc.5。
