# 2.10.0 — 角色设定与聊天行为分层

角色配置优先参考 qq-bridge 的自由文本角色与共享聊天预设设计，减少填写负担和服务式闲聊倾向。

- 角色设定支持一份自由文本，几条习惯即可启用；示例、动机、世界背景不再必填。
- 旧设定、开场参考和正反例完整合并展示。编辑后的新文档为唯一角色文本来源，旧字段与背景资料保留。
- 独立聊天规则强调直接反应、自己的态度、说到点上停止、相关记忆和自然收尾。可设置闲聊节奏、少量动作和额外偏好。
- 每轮刷新简短聊天提醒，记忆服务关闭时也生效；不更改原始历史，不额外调用模型。
- 工具注册、权限和真实任务交付能力完整保留；工作流程适用范围明确，普通闲聊无需自动进入看板。
- 分段配置为角色设定、聊天方式、试聊、相处记忆；首次三步引导使用通用示例，旧资料按需展开。

未新增 QQ 渠道、工具驱动发送、分段气泡、故意延时或潜水。正式私聊仍需可见回复。试聊是隔离预览，不执行工具或发送真实渠道消息；正式会话的工具能力不受影响。

兼容原 schemaVersion 1，新增可选 roleText/chatStyle 字段。关闭角色聊天继续使用旧身份。回退到旧包前应备份新角色文档，旧版本不会读取新增字段。
