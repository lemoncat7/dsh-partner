# 2.11.6 — 减少记忆与关注读取的重复写盘

- 数据库结构初始化改为按 schema 版本升级执行；正常读取不再重复建表、检查字段和写入版本号，减少同步磁盘 I/O 对宿主线程的影响。
- 记忆 schema 升至 2，关注 schema 升至 5；保留旧字段兼容迁移，结构、数据和版本号在同一事务中提交，失败整体回滚。
- 全文索引和关注标题迁移采用保存点，兼容外层迁移事务；初始化失败关闭连接，冻结期间拒绝继续打开数据库。
- 不降低 SQLite 持久化保障，不删除既有记忆或会话；高于当前支持的数据库版本会明确拒绝访问。
- 包含 2.11.5 的 20 张 Blobfox 内置表情与身份中的闲时主动联系功能。

详细说明：[存储读取与初始化](../storage-read-performance.md)。
