# 2.1.0 · 提问来源与渠道头像

正式版，已验证宿主 **DSH 0.1.5-rc.1**；要求 Node.js **^22.19.0 或 >=24.0.0**。保留旧宿主兼容分支，未重新完成全部旧宿主端到端验证。

- 交互提问根据当前用户消息的实际来源返回 DSH、微信、Matrix 或 Mattermost，不再根据会话历史绑定选择渠道。
- 持久化渠道消息来源标识；浏览器消息、无法识别的历史消息使用原生提问。已发出的提问固定原渠道与用户，发送失败不会误投其他渠道。
- Matrix / Mattermost 提问可独立接收答案，支持取消、停用渠道和撤回配对后的清理与权限检查。
- 默认提供 `partner_channel_avatar`，无需单独开启能力。支持查看自身渠道、使用当前会话目录中的 PNG/JPEG 修改账号头像。
- 校验真实账号、文件路径及大小；禁止修改其他伙伴或跨伙伴共用账号，上传和设置之间重新验证归属。

443 项自动化测试及 6 组响应式/主题界面检查通过。渠道头像接口通过本地模拟服务验证，未对真实 Matrix / Mattermost 账号执行头像变更。

升级不改变 2.0.0 的存储迁移规则，安装不会自动迁移。详见 [存储迁移说明](../storage-migration.md) 与 [提问来源与渠道头像](../channel-questions-and-avatar.md)。
