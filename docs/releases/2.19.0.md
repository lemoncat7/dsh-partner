# 2.19.0

角色与关系分开保存：角色设定只描述自身身份、性格、语气和通用示例；身份新增独立「关系设定」，描述与用户的关系、称呼和专属相处方式。默认适配器合并使用；QQ 适配器仅在真实发送账号匹配访问权限中的任一归属 QQ 时附加关系，群聊与私聊通用。未绑定或未知发送者不附加关系。原有工具授权仍是上限，不强制陌生人冷淡。

- 页面与 AI 共享一份生效身份，不再维护独立草稿。AI 使用 partner_identity 分别编辑 characterCard.roleText 与顶层 relationshipText；页面直接展示最新设定，正在编辑时保留未保存内容并提示版本冲突，防止覆盖。旧草稿仅保留在部署备份中。生成指导与参考说明同步更新。
- 试聊可选择普通会话、QQ 归属账号、QQ 其他账号；不投递渠道、不写正式记忆。
- 旧的独立 characterCard.relationship 兼容读取；显式清空新字段可取消旧关系。旧自由文本中的关系不自动猜测删除，页面提示人工或 AI 拆分，旧文本不丢弃。
- 每轮根据持久化消息来源核验发送者，不采用昵称、自称、引用或群号；共享会话切换不追加系统头。QQ 非归属对象不自动附加共享相处状态和用户画像。历史消息和显式记忆检索仍保留，不把关系选择器当作记忆访问权限。

QQ 归属支持多个账号（最多 100 个）。未归属 QQ 用户只获得当前会话的文字、表情与语音回复工具：模型请求不提供私有工具，执行入口使用 DSH 单调拒绝 guard 重新核验账号，阻断旧工具调用、按需发现与代码入口。已核验归属账号及系统发起的自主活动/内部任务沿用既有能力开关与授权。群聊自主接话仍按实际发言人核验，不因机器人决定回复而获得自主执行权限。

工具提供同样通过渠道适配器：默认保持会话既有工具；QQ 自行判定归属或系统自主执行，决定提供既有完整工具还是受限回复工具。模型装配与真实执行共用适配器结果。未归属聊天也不能通过记忆整理新建、停止或修改关注任务；含未归属发言的每日终审不变更关注，已归属发言仍可在逐轮整理中维护关注。

配置页面分为「聊天回复」与「私有能力」，标明适用对象。新增当前会话语音工具，只接受文字/音色，固定真实回复目标，不接受文件、URL、收件人或任意 API；群内直接使用 QQ 文字转语音，私聊借用所选已接入群的音色合成后仅发送到私聊。普通语音开关独立于私有能力，后者继续控制音频文件、空间、管理等操作。
