# 2.11.1

渠道发出的结构化聊天回复现在会作为正文显示在网页会话中，不再随原生工具过程一起折叠。已有记录重新打开即可显示，无需修改日志或重发消息。结果事件继续传给原生工具节点，避免其结束状态丢失。

开启分段回复后，简短偏好约束单条消息，不再暗示整轮只能一句；有不同接话点时优先分别提交。每轮上下文会明确当前分段和表情开关。表情工具说明列出实际内置表情 ID，允许直接选择；自定义和不熟悉的图片仍可搜索、查看，服务端继续校验开关和库内资源。无需强制每轮拆句或附图，工具与工作能力保持不变。

验证：聊天投递、角色提示、记忆上下文回归测试；生产会话只读可见性检查使用 `ops/verify-chat-visibility.mjs`，断言实际聊天节点不属于折叠过程且高度大于零。隔离模型试验不执行工具、不写正式会话、不发送渠道消息。
