# 2.25.0

伙伴插件正式版，汇总此前 2.24.0-rc.10 至 2.25.0-rc.11 已部署的改进。

支持宿主 **DSH 0.2.2-rc.1**，需要 **Node.js >=24.9.0**。插件为正式版，宿主版本仍为 RC；不表示支持其他未经验证的宿主版本。

## 聊天与自主活动

- 普通聊天和中途接话保留主模型成稿，取消额外语气改写，保留权限、输入变化和交付检查。
- 恢复普通最终回复的分段兜底。「短句接话」每段半句到两句，各类标点合计最多三个，可超过三段；保留代码、引用和明确特殊格式例外，不强行截断。
- 自主活动区分共同话题、私人探索与未获回应的主动发言。新话题交代必要来由，不把自己的经历当成对方已知背景，也不把无人回应的故事自动连载。
- 增加活动时间线、分类、发送回执与作品关联，支持展开更多记录。
- 语音、表情包和渠道互动通过 partner_tools 的 activity 目录发现；普通聊天也可使用，执行仍检查实时授权。

## 通用语音 TTS

- 渠道页面按通知、消息、TTS 分区，通用服务独立管理，支持 BreezeBlue、OpenAI 兼容 speech 和自定义同步 HTTP。
- 支持服务试听、渠道音色绑定；QQ 发送语音，微信、Matrix、Mattermost 发送音频附件。密钥保存在凭据库，不注入模型上下文。
- 新增 send_file，直接发送当前会话工作目录中的 WAV/MP3，支持脚本生成后连续试听不同音频，无需配置 TTS 服务。
- 保留投递回执、去重、文件边界与权限检查；结果未知时不自动重发。

## 关注与运行状态

- 修复关注记录同步反复检查，提供片段更新、版本校验和持久失败退避。
- 恢复关注执行前核对原执行结果；已完成则修正回执，避免再次派发。卡片显示真实结果及未解决的外部阻碍，不把完成核对当成产物已交付。
- 后台记忆整理等伙伴级任务在总览显示一次，渠道任务按真实输入来源显示。

## 验证与升级

完整回归 1432 项通过；正式包执行资源完整性检查。此前 RC 已部署验证健康、QQ 状态与会话历史。隔离模型回放用于检查自主聊天决策，不能保证每轮主观语气效果。

升级前备份数据，安装后重启对应 Profile；已有 TTS 服务及渠道绑定沿用，无需重新填写。人物设定不迁移、不在插件逻辑中写死人物口吻。
