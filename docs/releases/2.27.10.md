# 2.27.10

- QQ 私聊和群聊中的调查、文档、生图、编程任务使用 DSH 原生后台入口，完成后按原始来源回传；补充和取消限定原发起人，普通聊天不改变任务目标。
- 生图工具增加执行检查，已绑定 QQ 账号的前台生图调用需先交后台；后台正常执行，避免生图长时间占用聊天。后台产物校验文件范围，结果投递保留去重和授权检查。
- 修复已被本地模型识别为呼唤的群消息仍被随机旁听过滤的问题；忙碌时也识别呼唤并排队，普通群消息继续旁听，不打断工作。
- 同一发言人先发图片、后补说明时，五分钟内首次进入回复的消息自动携带待处理参考图；保留来源隔离和一次提交限制。
- 优化模型准备阶段：按会话配置和内部标记选择工具，缓存工具视图，减少完整状态复制、重复历史扫描和工具重组。
- 包含 2.27.8、2.27.9 的回复时效、连续输入处理和可配置分段间隔改进。
