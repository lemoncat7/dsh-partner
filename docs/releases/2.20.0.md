# 2.20.0

- 开启统一伙伴工具入口后，模型常驻 `partner_tools`（查询/调用）与 `partner_channel_access`（当前渠道账号能力）两个入口。聊天、表情、语音和工作工具都经入口调用。
- 默认渠道沿用既有授权，QQ 按可信发言来源实时过滤能力；归属账号、普通成员和可信自主任务仍各自遵守原权限。账号切换不再切换 native/PTC 或增删顶层工具。
- 原工具仍在 DSH 运行时执行，保留原参数校验、审批、取消、结果展示、附加上下文与回合终结。兼容 `load` 为查询说明，不再改变顶层工具集合。
- 连续消息追加到当前回合时，不再往渠道发送“已插入当前处理”提示。
- 并行执行独立 QQ 身份检查，合并首次通知记录与发送尝试的落盘，减少未变化伙伴的目录扫描；权限核验、原子提交、同步落盘与恢复语义保留。
- 渠道状态接口提供最近 20 条消息的阶段耗时，仅记录消息 ID、耗时与结果，不记录正文或凭据，便于区分模型判断、会话收尾、状态保存与发送等待。

此前生成结束后约 11 秒的等待已定位在会话收尾到发送记录建立之间；历史日志不能进一步确定具体阻塞点。本版增加阶段计时供下一轮实测，不宣称已达到 5 秒回复。
