# 2.18.0

QQ 渠道 → 访问权限新增可选的“身份关系绑定”。填写主归属 QQ 号及这个人在人设中的关系（例如角色是弟弟，对应关系为“哥哥”）。只有绑定账号对应这层专属关系；对其他人的态度由人物性格与实际交往决定，不额外规定冷淡或亲近。

- 私聊与群聊从渠道真实发送者和已存消息来源判定，不采用昵称、自称或正文中的号码；共用会话仍逐轮区分发言人。
- 绑定不授予配对、工具或主会话权限；默认关闭，旧配置继续生效，关闭后保留填写内容。
- 设置在后续回合生效；本地网页对话保持原有身份。群聊自主活动没有明确个人对象时不推定为绑定人。
- 群聊接话判断沿用同一绑定规则。记忆提炼携带 QQ 关系归属，不允许其他成员的轮次改写共享状态中的绑定关系；不迁移历史记忆。
- 关系是提示词中的明确约束，并非身份认证或新的访问权限。渠道授权与工具权限仍分别管理。
