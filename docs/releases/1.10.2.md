# 1.10.2

兼容 DSH v0.1.2-rc.1。

本次正式发布包含本地 1.10.1 与 1.10.2 的修复。

- 最新需求、补充说明及打回理由统一传入返工上下文，保留上次交付；过时执行或验收结果不能覆盖新版任务。
- 阶段通知与归档解耦：只剩已完成/受阻且没有排队执行才汇报；待开始、执行中、待验收不触发通知。汇总和去重记录持久化，网络失败及重启后可继续重试。

- 伙伴创建看板任务必须明确指定所属需求；漏填 requirementId 不再静默新建独立需求，依赖 ID 不能代替需求归属。
- 同一目标继续下一阶段时复用原需求；已提交或已归档的需求可以明确重开，保留已验收任务、旧归档成果和通知记录。
- 区分追加阶段与重做旧交付：扩展新阶段范围不自动重跑旧任务，仅重开也不会重复发送上一批成果。
- 内置“任务拆解与看板推进”技能更新至 1.4.1，明确续做、阶段范围确认与通知边界；不增加前置 Skill 或额外分工闸门。
- 保留原有 UI 样式；提供受版本及完成状态检查保护的显式归属修复逻辑，不自动合并历史数据。
