# 2.25.16

支持 DSH **0.2.2-rc.1 / 0.2.2-rc.2**，Node.js **>=24.9.0**。

- 群聊连续输入以首条确认送达为界：普通聊天未回复时同一人的补充继续合并，不再受固定 5 秒限制；已有一段送达后，普通追话只旁听，先完成本轮分段回复。
- 发送状态覆盖中途文字、语音和附件回执，以及最终消息的逐段发送；失败或空回复不算已送达。
- 本轮结束时已收到、仍滞留在合并缓冲中的普通消息不会再开启旧话补答；真正结束后收到的新消息正常判断，没有额外冷却期。短期状态有数量上限，不写入长期记忆或会话日志。
- 已进入工具工作的任务继续保护；任务发起人的明确取消、修改仍可插入，明确的新呼唤可排队。不同群、渠道和发言人不会共用发送状态。
- 放宽普通群聊的接话机会：其他成员正在聊天不再一律提前过滤，本地语义判断有交流意味时保留概率性接话；每群限制主动插话的准入频率，直接呼唤与已有对话不受此间隔限制。语气和是否最终开口由当前人物与上下文决定，未写死吐槽词或台词。
