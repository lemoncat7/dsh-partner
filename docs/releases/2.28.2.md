# 2.28.2

- QQ 群聊只合并同一人紧邻、发送时间也接近的消息。其他群友插话会分开处理，网络积压也不会把时间相隔较远的消息算成一批。
- 群聊发言按顺序进入回复队列。同一秒内的群友发言与已送达的伙伴回复按实际收发时间排列，避免上下文漏掉刚发送的回复。
- 保留连续补充和图片说明的合并，以及任务进行中的补充和打断机制。详见[群聊本地识别](../qq-attention.md)。

升级后重启对应的 DSH Profile。验证包括全量测试和容器内回放，覆盖插话、积压消息、同秒收发和连续补充。安装与运行边界见[宿主兼容策略](../host-compatibility-policy.md)。
