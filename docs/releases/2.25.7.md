# 2.25.7

支持 DSH 0.2.2-rc.1。

- 同一私聊近期执行任务后，将原请求、近期回应及真实操作回执作为有界的任务接续上下文。用户纠正做法或补充要求时，承接原目标继续当前轮工作，不用承认问题、复述方法代替执行，不交给闲时自主活动。
- 文字、通用 TTS、QQ 原生语音在最终回复前统一检查任务判断。声称有进展或完成时必须引用本轮成功操作；旧轮回执、工具目录、说话和失败结果不能作为依据。回执仅证明操作，是否达到目标仍需模型结合当前请求判断。
- 保留只讨论、暂停、取消和新话题的正常回应；不扩大原有权限，不跨聊天对象或群聊继承任务。当前轮未核对便停止时最多恢复两次，并提示复用已有结果、不重复工作。
- 不增加分类或改写模型，不写死角色语气，不新增会话事件类型，不修改页面历史或滚动规则；任务信息从原始日志有界投影，兼容静态人格独占模式。
- 保留 2.25.6 的 TTS 尾音保护、同轮分条回复与自主活动改进。
