## 兼容性

正式版，适配 DeepSeek Harness **0.1.2-rc.1**；Node.js ^22.19.0 || >=24.0.0。知识库挂载管理需搭配 **dsh-knowledge 2.4.0+**。

## 更新

- 修复删除伙伴后下一位伙伴仍进入删除确认的问题；确认绑定目标、切换重置、操作防重，删除成功返回总览。
- 页面明确确认后，清理伙伴专属 partners/<id> 目录、工作区注册及关联配置；不扫描历史遗留目录。共享路径、符号链接根目录和挂载点受到保护。
- 删除期间阻止新会话及后台任务重新占用目录；运行中、绑定渠道及最后一个伙伴不可直接删除，清理失败保留身份供重试。
- DSH 当前公开 API 不支持永久清理全局原始会话日志，因此这些日志仍保留。文件清理不构成跨存储事务，失败时可能已有部分文件删除。
- 包含 1.9.0 的主动任务拆解、持久化看板调度与紧凑看板布局更新。

## 验证

180 项自动化测试通过；手机、横屏、桌面深浅色共 6 组隔离删除交互验证通过。本地部署同一构建包并逐文件校验，检查 3080 与 3081 服务健康。未修改 DSH 核心代码。


## 从 README 迁入的历史说明

### 1.9.1 更新：伙伴删除与目录清理

- 删除确认绑定当前伙伴，切换伙伴时重置；删除中防止重复操作，成功返回总览，不再把下一位伙伴置于删除确认状态。
- 页面明确确认后，移除伙伴专属 `partners/<id>` 目录及文件、工作区注册和关联配置；共享目录、链接根目录与挂载点拒绝自动清理，不扫描历史遗留目录。
- 删除期间阻止新会话、后台任务与执行队列重新占用目录；运行中的伙伴、已绑定渠道与最后一个伙伴受到保护，清理失败保留身份供重试。
- DSH 当前公开接口不支持永久清理全局原始会话日志，因此这些日志仍保留；目录删除不是跨存储事务，文件删除失败时可能已有部分文件被移除。
- 180 项自动化测试及手机、横屏、桌面深浅色共 6 组隔离交互验证通过。
