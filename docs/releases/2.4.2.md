# 2.4.2 · 渠道回复分块与通知可靠性

支持 DSH **0.1.5-rc.1** 系列，Node.js **^22.19.0 或 >=24.0.0**。保留既有旧宿主兼容声明。

- Mattermost 将正文、工具状态块和最终回复分开发送；只更新当前工具块，无需安装额外服务端插件。
- Matrix / Mattermost 接受插入消息后切换展示段，避免持续编辑最初的回复。
- 工具块只展示名称、状态和耗时，不转发参数、原始结果或推理内容。
- 通知投递增加超时边界及失败阶段记录，保留已成功部分，重试不重复发送这些部分。
- 权限撤销、中断及迟到的工具结果不会重新打开已结束的展示段。
