# 2.19.1

QQ 聊天许可按三种情况判断：私聊需要账号审批；自主回复白名单群放行所有成员，无需逐人配对；其他已接入群需要审批发言账号。私聊与各群的审批分别记录，不互相继承；明确屏蔽的成员仍不回复。群白名单无需 @，由伙伴判断是否接话，不保证每条必回；其他群沿用 @ / 全部消息的触发设置。

入站、文字、分段、表情、语音、原群通知和闲时联系共用许可判断；发送前重新核对群白名单、账号审批、开关与屏蔽状态，撤销后不继续发送。真实来源决定接收群，不创建隐式私聊授权、不转到其他会话。排队消息也读取最新设置。

群内许可只允许正常回复，不增加私有工具或关系权限。页面明确区分群接入范围、白名单、账号审批与归属账号。升级保留现有私聊开关、群列表和审批记录。
