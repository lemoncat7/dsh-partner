# 2.26.4

支持 DSH 0.2.2-rc.1 / 0.2.2-rc.2，Node.js >=24.9.0。

- 伙伴向本群实际送达回复后的三分钟内，其他成员的相关补充可按共同续聊进入，不再重复抽取新插话概率或等待主动插话间隔；只有真实发送延长窗口，旁听与仅入队不延长。
- 共同续聊需有近期话题关联，明确转向他人、收尾和强负向分类仍过滤；不将新成员的发言误并到另一人的当前回复中。
- 主模型群聊说明提供真实近期参与状态，区分共同话题和明确发给其他人的消息；换人不等于退出话题。保留可选择安静结束，不强制逐条回答或硬编码人格台词。
- 保留五秒非定向插话间隔、任务防打断、首条送达后的输入窗口和现有识别服务。无需更新识别模型或角色设定。
