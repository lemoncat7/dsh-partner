# 2.23.4

QQ 渠道表情库模式仅查询和使用该账号的收藏、系统表情，不再在搜索无匹配或目录离线时自动混入内置图片。需要默认库时可明确切换来源。

收藏成功和已收藏去重结果返回可直接用于聊天的 stickerId，并提示补充名称、情绪、适用场景备注。角色聊天提示明确：按人格在收到图片时判断收藏意愿，收藏与发送分别执行；无匹配时可浏览收藏，收藏整理不需要任务进度播报。没有改写用户人格或强制每轮发图。

查询、添加、备注、置顶、删除 QQ 收藏改为公开聊天能力，按当前渠道的单项开关执行，不依赖归属账号或私有能力总开关。普通账号不可借此访问其他渠道、空间或账号管理。设置入口移至「表情与图片」；当前会话语音原本已公开，补充工具说明以支持按人格自行选择。语音仍只发送到当前会话。

表情管理是否执行由 AI 根据人格、喜好和实际需要判断，单项开关只控制能力是否可用，不要求用户逐项发令。
