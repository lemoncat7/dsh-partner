# 2.21.13

插件版本：**2.21.13**。部署验证宿主：DSH **0.2.1-rc.5**。保留原有最低 rc.2 依赖兼容范围。

包含 2.21.12 的独立会话并发、群聊判断隔离、回复后概率自主活动、主会话记忆收录与中文生图工具发现改进，详见 [2.21.12](2.21.12.md) 和[行为说明](../conversation-autonomy.md)。

修复私聊任务只调用工具、不生成前置正文时一直沉默的问题。新增非终结工具 `partner_chat_progress`：回应由当前角色生成，确认送达后继续任务。实际工作工具在 pre-execute 阶段等待前置回应，缺少回应时返回纠正指引且不执行。发送失败或结果未知时不重复发送、不放行工作；普通聊天和工具目录查询保持直接处理，群聊与自主活动不强制套用私聊回应。

保留最终回复流程。前置回应不会结束回合，也不会再次触发回复后自主活动。

修复自主活动选择休息后仍发送解释文字：宿主 compact-checkpoint 摘要不再作为新用户输入阻止静默结束；实际调用 partner_activity_finish 即保留静默意图，即使结束工具失败也不转发兜底正文。重启后的待发送恢复同样检查对应活动的静默决定。真实用户新消息仍不能被静默工具跳过。

验证：全量 1052 项测试通过；rc.5 生产部署、网页与插件设置验收通过。未发送真实测试消息或触发付费生图。
