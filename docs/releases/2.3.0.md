# 2.3.0 · 统一记忆、用户概述与 Matrix 恢复

正式版。已验证宿主 DSH **0.1.5-rc.1**，Node.js **^22.19.0 或 >=24.0.0**。
保留旧宿主兼容声明，未重新完成旧宿主的全部端到端验证。

## 记忆与画像

- 同一伙伴、同一主会话的渠道共享用户记忆范围；迁移保留原始轮次、依据和关注来源。
- 修复提炼证据字段缺失、历史空结果及长期偏好未展示的问题；无依据的结果重试，不伪装成功。
- 新增独立用户概述，区分明确表达与多轮观察；不将临时任务、工具调用或项目进度当成人物特征。
- 画像、偏好等统一为可筛选记忆列表；用户概述可展开阅读，依据和纠正按需展示。
- 后台画像任务持久保存租约和退避状态，失败保留旧画像，纠正使旧任务失效；输入不变不重复调用模型，自动更新间隔至少十分钟。
- 修复记忆设置、每日回顾等弹窗的视口居中、焦点与滚动保持。

## 渠道

- Matrix / Mattermost 按 DSH 会话设置选择插话或排队；输入准备与长时回复分离。
- Matrix 同步消息缺口使用房间分页接口补拉，按事件 ID 去重；失败保留原游标。
- Matrix 满载输入队列等待空位，不直接断开；临时网络故障持续退避重连。
- 首次连接仍不执行历史消息，补拉不绕过双人房间、成员及加密限制。
- 未修改 Mattermost 的地址、DNS 或凭据，网络可达性问题需要单独处理。

## 边界与验证

- Matrix 单房间补拉上限100页、10000事件、16MiB；超限明确报错并保留游标。
- 认证、权限及投递异常仍停机保护；不承诺跨模型回复与渠道发送的严格恰好一次投递。
- 用户概述旧版本保留最近五份，暂未提供历史版本浏览界面。
- 升级前备份插件、公共数据及各伙伴的私有数据目录。
- 501 项自动化测试通过；桌面、手机、平板及深浅色界面检查通过；本地部署验证 Matrix 恢复 running。
