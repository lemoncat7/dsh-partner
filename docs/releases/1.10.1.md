# 1.10.1

兼容 DSH v0.1.2-rc.1。

- 修复需求变更、补充讨论和打回理由未进入返工上下文；保留上次交付与内部交接，已通过任务不携带历史返工指令。
- 需求或任务内容修改会取消旧执行，迟到结果不能覆盖新版；通过/打回必须针对实际读取的任务版本。
- 阶段通知与归档解耦。仅当非空需求只剩已完成/受阻任务且没有排队执行时汇报。收集箱、待开始、执行中、待验收均不触发通知，也不作为阶段通知内容。
- 阶段内容与去重标识持久化，发送失败可重试，重启复用已有汇总；继续添加任务会使在途旧汇总失效。
- 已确认完整范围并全部验收完成的需求自动总结归档；负责人也可明确完成全部任务已通过的规划态需求，不通过删除未完成任务伪造完成。
- 保持现有界面样式与 DSH 核心代码不变。
