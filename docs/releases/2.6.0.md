# 2.6.0 · 导演技能与长任务最终交付

正式版。验证宿主 DSH **0.1.5-rc.1**；Node.js **^22.19.0 或 >=24.0.0**。保留 DSH 0.1.2-rc.1 兼容声明，旧宿主未作为本次部署验证基线。

- 内置可选“影视创作工作流”和“导演与分镜设计”，固定上游提交、保留 MIT 许可，资源离线打包并校验，不自动安装或授权。
- 独立长任务只投递最终回复和附件，不发送预约完成、受阻等内部状态；最终回复独立持久化重试，不重新提交外部生成任务。
- 新预约记录原渠道和联系人，续接附件与最终回答回原渠道；目标失效不切换到最近联系人。来源不明的旧预约不猜测发送。
- 独立受阻预约允许原会话凭准确外部 ID 补交完成证据；过期轮次、跨会话与看板任务仍受状态检查保护。
- 修正持续关注已解决项删除按钮布局；“归档关注”改为“已停止关注”，空记录不显示入口，保留历史清理能力。

验证：构建及 590 项自动化测试通过；渠道来源修复已通过本地构建部署与健康检查。新版技能说明同步明确“只投递最终消息”。
