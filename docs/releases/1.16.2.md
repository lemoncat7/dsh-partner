# 1.16.2

伙伴插件正式版。已验证宿主：**DSH 0.1.5-rc.1**；要求 Node.js **^22.19.0 或 >=24.0.0**。保留旧宿主兼容分支，未重新完成全部旧宿主端到端验证。

- Matrix / Mattermost 支持正在输入状态；较慢回复创建进度消息，完成后编辑成正式回复，快速回复不额外创建进度消息。
- 工具调用仅显示概括状态，不公开工具参数、结果或推理内容。节流更新，完成、失败和取消后清理监听与定时器。
- 协议传输、进度生命周期和模型事件映射分层；进度失败不阻断模型执行，明确不支持编辑时回退发送。
- 悬浮卡片消息详情支持标题、强调、列表、任务清单、引用、链接、代码块和表格；列表保持紧凑摘要。
- Markdown 使用安全 AST 渲染，原始 HTML 作为文字，危险链接不可点击，远程图片转为链接。宽表格和代码块局部滚动，适配深浅色与窄屏。

395 项自动化测试通过，Markdown 浏览器检查与部署页面/API 检查通过。具体正在输入和消息编辑显示依赖渠道客户端；不新增 Matrix 加密支持。旧消息不会自动转换为进度消息。
