# 2.11.7 — AI 生成人格与人工草稿分离

- 可在聊天中描述想要的人格，由伙伴通过 `partner_identity` 读取、生成并保存自己的完整身份；无需开启伙伴管理权限。支持人格正文、聊天偏好、背景资料、基本身份及闲时联系设置，其他工具能力保持原样。
- 页面编辑人工草稿，保存时同时应用到实际身份。AI 只编辑生效内容，不改人工原稿；旧身份在第一次修改前保留为草稿。页面可查看生效版本，也可将其复制到编辑区后手动保存为原稿。
- 身份保存带版本检查；并发编辑不会静默覆盖。页面保存是完整替换，AI 局部修改会保留未指定字段，数组完整替换。已授权的伙伴管理工具也支持人格配置，并保留目标的人工草稿。
- 免打扰可独立开关，关闭时保留时段。旧配置默认保留原先免打扰行为。
- 取消闲时主动联系每日上限，旧配置中的 dailyLimit 不再限制发送。仍遵守空闲间隔、用户未回复不追发、会话忙碌等待及渠道授权规则。

验证：身份生成与应用、旧身份原稿保留、重启持久化、页面保存、并发冲突、跨伙伴隔离、权限字段拒绝及免打扰/无限次回归测试；生产页面只进行不落盘交互验证，不发送渠道测试消息。
