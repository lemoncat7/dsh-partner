# 1.16.0

伙伴插件正式版。已验证宿主：**DSH 0.1.5-rc.1**；要求 Node.js **^22.19.0 或 >=24.0.0**。保留旧宿主接口回退，但未重新完成旧宿主的全部端到端验证。

## 更新

- 伙伴级通知设置：多选渠道，再选择各渠道的已授权接收人；支持最近联系渠道与用户模式。
- 普通聊天回复、交互式审批与明确发送到当前会话的附件仍走来源渠道，不随通知设置群发。
- 通知多目标独立投递；逐项持久化正文、附件的已确认进度，重启与重试跳过成功部分。关注使用观察记录 ID 标识通知，单条通知失败不阻挡其他通知。
- 保留旧联系人投递规则，首次保存新配置后统一接管；编辑身份不丢失通知配置。
- Matrix 检测房间加密状态、加密消息和加密邀请；跳过不支持的加密房间并在渠道卡片直接提示，不影响其他未加密会话。仅未加密双人会话可获取配对码。
- 身份与渠道表单隔离主题覆盖；通知弹窗按渠道组织接收人，支持窄屏换行、失败保留输入和键盘操作。

## 边界

通知配置修改仅影响新通知，待重试通知保留原接收人并重新校验授权。原有处理流程触发重试，不新增无限重试任务。远端接受但网络丢失确认时仍可能重复；已完成回执有限保留，待处理记录不静默淘汰。

所有获准联系人仍共享同一伙伴上下文，请仅授权可信联系人。Matrix E2EE、群聊及新增渠道附件仍不支持。

## 验证

380 项自动化测试通过。浏览器验证包括 375/1024 宽度、浅深色、通知多选、失败重试、键盘关闭及渠道卡片提示。线上服务与 API 健康，已确认真实 Matrix 加密提示显示在配置弹窗外；未发送测试通知或改动用户接收人配置。
