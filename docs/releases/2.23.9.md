# 2.23.9

工作流程按需加载：聊天系统提示只保留能力入口、Skill 名称与概要。看板、委派、验收、定时和管理流程通过工具 describe 或 partner_workflow inspect 获取，inline Skill 正文通过 partner_skill load 获取；原执行校验与授权不变。

新增 partner_work_execute，将复杂调查、多步操作放入临时工作会话，只将事实、未知项、证据、产物和调用回执返回原会话，由原人格继续答复。普通聊天和轻量工具可直接执行，已有看板任务不重复创建。私聊执行前继续使用人格化前置回应。

工作会话调用仍走原会话工具管线与实时权限；取消、来源变化、撤权会阻止后续调用，禁止通过临时会话使用额外原生工具或直接回复聊天。只有目录查询时，完成状态降为未验证。未提交结构化结果不得视为完成。

不修改角色卡、聊天历史或滚动窗口规则，不加入统一口吻、硬截断或每次回复的二次改写。独立工作会增加模型调用，是否采用此入口仍由模型根据任务选择。
