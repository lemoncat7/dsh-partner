# 2.9.0 — 人格强化与每日上下文焕新

兼容 DSH 0.2.1-rc.2，Node.js ^22.19.0 或 >=24.0.0。

身份页新增可选人格卡：首次使用四步弹窗，已有内容直接编辑。包括角色核心、动机、语言、对话示例、关键词世界条目及独立角色记忆。试聊不写入正式会话或发送渠道。没有卡片或关闭人格强化时保留原身份逻辑；引导使用通用示例。

记忆设置新增独立的「每日上下文焕新」，默认开启、每日 04:00（插件时区）。关闭学习也会定时焕新；开启学习时先补齐未归档内容、提炼与终审，成功后才清空，失败延后重试。等待当前回合结束，保留受保护系统头和原始聊天历史。每天每会话最多一次，计划时间之后启动服务会等待下一天，不立即重置现有会话。每日终审开关不影响焕新所需的整理。

历史检索增加全文索引，解除最近 100 轮限制，提供限定当前会话范围的记忆检索工具。召回依赖保留的归档，不保证所有细节自动出现。

存储变更为新增角色状态、焕新记录与历史索引。部署前应备份伙伴状态与记忆数据库；原会话日志不重写。详情见 [功能说明](../character-cards-and-renewal.md)。

验证：758 项自动化测试通过；375px / 1280px、明暗主题的引导、试聊、保存与独立定时设置浏览器测试通过。原生 Session 测试覆盖系统头保护、历史重放、幂等、写入失败重试和并发消息保护。
