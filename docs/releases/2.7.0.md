# 2.7.0 · 适配 DSH 0.1.7-rc.2

插件正式版（非 prerelease），已验证宿主：**DSH 0.1.7-rc.2**。宿主本身仍是 RC，不代表已验证所有未来版本。Node.js：**^22.19.0 或 >=24.0.0**。

## 更新

适配 Preset Registry、producer-owned 消息来源、会话导航、目标通知和下一轮能力注册；保留看板交付、微信重连及内置漫剧技能。附件副本统一存放到公共 attachment-deliveries/<伙伴编号>/，支持共享额度、筛选清理、保护活动任务引用、可续接校验迁移；紧凑设置及统一清理弹窗。

## 升级与回退

- 本版面向 DSH 0.1.7-rc.2，不应直接安装到 DSH 0.1.5 或更早宿主。
- 升级前源码快照：`pre-dsh-0.1.7-rc.2`（提交 ab7301e，插件源码版本 2.6.0）。历史正式标签保留，不移动或覆盖。
- 旧版 npm 安装参考：`npm install @lemoncat7/dsh-partner@2.5.0`；升级宿主前先备份配置、数据库及工作目录。
- 新版安装：`npm install @lemoncat7/dsh-partner@2.7.0`。
- 附件目录会迁移，ID 与历史链接保持不变。回退旧代码须恢复配套存储备份并妥善保留升级后的新数据；不能只降级插件包。

## 验证边界

本地构建和自动化测试通过；DSH 0.1.7-rc.2 隔离容器已验证插件启动、适用的设置页面和接口。正式容器已经部署对应兼容代码并完成页面/API 冒烟检查。

未穷举 Windows/macOS 桌面桥、真实远端 SSH/FTP、所有渠道端到端附件投递及付费模型提供方。没有把本次验证扩大为对所有外部服务的保证。
