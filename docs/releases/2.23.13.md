# 2.23.13

工作回复改为显式事实交接：主会话决定当前回应目的，并引用本轮真实工作结果的 runId 和数组下标；回复阶段沿用原有人格、关系及模型，一次生成最终文字。普通聊天、用户换话题和直接提交的 messages 不再被自动二次改写。表情仍使用真实库 ID，原有分段设置继续生效。

交接只接受当前回合、同一回复对象的真实工具记录，选定工作记录的状态与未解决事项保留。工作执行器将结论和过程证据分开，便于选择相关事实；不追加固定口头禅、情绪或篇幅模板。

主会话与工作回复共同读取有限的近期休息记录、已确认送达的前置消息和语音文字，区分当时与现在。前置消息按调用来源隔离，不把失败、发送中或另一对象的消息当成已送达。读取原有历史形成上下文投影，不改写历史事件、记忆、人物设定或滚动策略。

交接生成失败时不发送、不结束回合，返回原会话直接作答；同一输入的失败交接不重复推理。生成期间及准备表情后再次检查输入、人物关系、休息状态与渠道授权，变化时停止旧回复。

修复数字校验把斜杠分隔的抽帧位置和列表编号当成错误事实的问题；选定交付链接仍须完整保留。数字和链接校验不等于完整语义验证。

验证采用自动化回归、真实历史的隔离模型选引用与 ToolRuntime 执行、失败后的主会话恢复，以及明确标注的合成成功/超时场景。没有向 QQ 发送测试消息。工作回答的报告口吻仍有残留，不能据此宣称人格表现已稳定达到“像真人”。
