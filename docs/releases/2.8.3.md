# 2.8.3 · 持续关注恢复与卡片按需加载

兼容宿主：DeepSeek Harness 0.2.0-rc.2。本版本不调整宿主兼容范围。

## 持续关注

- 分离来源变化与执行条件；已核验但尚未完成的工作也可触发执行，不仅依赖本轮是否发现新内容。
- 使用稳定执行标识和持久化回执去重，降低多轮检查、服务重启导致的重复执行。
- 提供失败执行的“核对产物并恢复”，先检查已有结果和外部状态，再决定是否继续，避免盲目重复副作用。
- 保存有界、经过清理的检查进度，配置变化或过期后失效；细分认证失败、权限不足及限流提示。
- 对明确声明需要认证的来源校验凭据与主机绑定，不额外授予命令权限。

## 伙伴卡片

- 先显示可交互的静态卡片及未读数字，后台按需加载 3D 渲染器与物理模块。
- 使用 DSH 原生版本化异步模块，支持加载去重、缓存和重试；加载失败时保留可用静态卡片。
- 禁用卡片时不加载渲染模块，再次启用复用模块；旧客户端端点支持 ETag/304。
- 新上传图片采用有损 WebP 压缩及 JPEG 回退，不自动改写已保存的图片；保留原有物理、反光及 3D 画质设置。

验证：构建通过，706 项测试通过；卡片加载、设置、坐标及鼠标交互浏览器回归通过；已在 DSH 0.2.0-rc.2 容器验证部署。
