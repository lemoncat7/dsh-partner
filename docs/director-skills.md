## 加载与权限

另提供用户整理的 `ai-camera-language`（AI 镜头语言与运镜），完整保留 32 项镜头词典、视频内容与时间索引、故事分镜及失败修订示例。原视频来源及作者见 `references/video-summary.md`；这是学习整理与扩展，不是原作者官方 Skill，不分发原视频和角色素材。

该技能专注镜头选择、物理运动、提示词与连续性，不替代导演总流程，不要求先使用画布。正文为 inline，三份参考按需读取；安装离线校验 SHA-256，缺失/损坏资源随现有内置修复流程恢复且保留伙伴绑定。DSH 仅增加显示名、版本、上下文类型与安装路径说明，不加载 Codex 专属 `agents/openai.yaml`。资源清单记录输入压缩包和原入口哈希；三份参考保留原文。

两个导演技能的中文 inline 入口保持精简，匹配任务后先读各自 `upstream/SKILL.md`，再按需读取所需参考和模板。不会将全部资料注入会话，也不会把九个子模块自动注册为工具或伙伴。两者同时启用时，前者负责阶段路由，后者仅细化相关导演环节。

资料需要已授权的文件读取工具；生成图像、视频、剪辑或文件交付需要对应工具或 MCP。技能不授予工具权限，不承诺资料中的模型能力仍然有效。多伙伴制作沿用需求/任务看板，外部长任务沿用一次性续接，不绕过授权、审批或预算。

## 分发与兼容

两个导演技能的 `resources/skills/<id>/upstream` 包含上游 Markdown 资料和 MIT LICENSE；仅统一为 LF 换行及末尾换行，不改写原文。CI 配置、运行脚本和非文档评测数据不随插件分发。

每个包的 `manifest.json` 保存来源、提交和逐文件 SHA-256；安装时校验并使用现有原子包安装器。安装无需 GitHub 连接；升级只跟随已审查的插件版本，不实时追踪上游。初始化检查已安装内置包的资源，缺失或过期时重装并保留伙伴绑定，不自动安装未选中的技能。

DirectorSKILL 上游使用多行描述和嵌套 YAML 元数据；本次不扩大通用解析器职责，使用兼容的薄入口，完整原文作为参考文件读取。入口版本与上游版本分别记录。

上游许可证分别位于两个资源包的 `upstream/LICENSE`，会一同写入已安装技能目录。影片、人物或素材权利不由这些 MIT 文档许可证授予。
