# 通用后台观察契约

后台观察不包含任何站点或发布平台专用逻辑。检查阶段从来源会话继承工具清单，不再通过固定白名单排除已授权的插件能力（包括 SSH）。实际调用仍走原生工具执行管线、父级权限及工具自身授权检查；可见性不是新增操作授权。模型只执行关注明确要求且已授权的操作。记录同步阶段仍限制为指定记录目标，检查阶段不能直接改写记录文件。模型在读取检查依据后先核对必要能力，缺少能力时报告具体步骤，不得借其他工具绕过权限。

结果分类：`changed`（新增）、`unchanged`（无变化）、`already_processed`（已处理）、`baseline_initialized`（首次基线）、`blocked`（核验未完成）。后三种成功状态不派发新增任务；首次空记录不自动视为错误，也不自动当成新变化。必须的历史核验缺失仍然受阻。

失败分类：能力缺失、认证、限流、网络、证据不完整、未知。限流恢复时间由实际响应提供为 ISO `retryAt`；仅 HTTP 403 不能断言限流。调度同时更新关注条目和伙伴唤醒时间，报告计划复查时间，实际执行仍受静默时段及服务状态影响。

其他插件可通过 `partnerObservationSources` 服务实现 `ObservationSourceRegistry.readTools`，返回 `observation_read_*` 只读适配工具。适配器必须自行核验伙伴/关注资源范围、凭据所属来源、分页及超时，并禁止任何写入。该服务是宿主代码显式接入点，不接受模型注册、不根据工具名字或并发安全标记自动授权，也不直接开放 SSH。

适配器是可选扩展，不是复用原会话已授权工具的前置条件。没有任何已授权访问途径的来源才报告能力缺失。说明内容及明文保存方式不变。
