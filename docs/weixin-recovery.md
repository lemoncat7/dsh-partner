# 微信渠道恢复

微信返回 `-14 / session timeout` 表示登录凭据失效，需要重新扫码；反复开关渠道不能更新凭据。

同一伙伴存在历史重复渠道时，微信面板展示全部记录及各自联系人。多个渠道同时启用时，启动检查会隔离冲突，不读取凭据或开始收件。

1. 核对机器人账号，停用不再使用的渠道。
2. 在需要保留的渠道点击“重新扫码”，使用同一个机器人登录。扫码会话绑定该渠道 ID，成功后原地更新凭据并保留联系人授权。
3. 如需清理旧渠道，点击“删除此渠道”并确认。该渠道凭据、配对和渠道会话关联会移除，不会迁移到其他机器人。
4. 等待渠道显示运行中，再发送测试消息；新联系人仍需审批。

如果扫码返回不同机器人身份，插件仍会拒绝接管旧授权。需要换机器人时，应先确认删除旧渠道，然后重新扫码建立渠道并重新审批联系人。

不要手工修改 storage v1 的 hash 快照。删除操作只能由用户明确确认，不会在启动时自动执行。
