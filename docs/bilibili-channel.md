# B 站渠道（2.24.0-rc.1）

渠道页添加“哔哩哔哩”，无需登录可搜索、浏览公开资料、读取可用字幕及生成视频链接。分享链接后需由现有授权聊天渠道发送；不会自动发到 B 站。登录后可按独立 API 开关启用评论/回复、点赞、收藏、关注、文字动态、视频链接动态、转发动态与通知查询。

“允许自主活动与账号互动”是活动目录和写操作的总开关。闲时触发沿用伙伴自主活动设置。登录只提供身份，不自动打开任何互动操作。每个伙伴独立渠道/登录凭证，不将评论区用户加入 QQ 的归属账号或长期关系。

目前为活动型渠道：通知由伙伴按需查询并用评论 API 回复；没有私信机器人、自动扫描全部通知或完整视频视觉理解。没有字幕时明确返回不可用，不声称看完视频。视频分享到动态第一版是文字加视频链接，不伪称原生投稿。

## 连接服务

`resources/bilibili/` 提供独立 Python HTTP 服务，依赖锁定 bilibili-api-python 17.4.2 / aiohttp 3.14.5，无 MCP SDK。接口参考 adoresever/bilibili-mcp，未使用其凭证文件。

构建：`docker build -t dsh-bilibili:0.1.0 resources/bilibili`。运行时挂载私有状态目录到 `/state`、随机令牌文件到 `/run/bridge-token`，服务用户 UID/GID 1000。仅内部网络连接，不公开端口。伙伴默认通过 `http://dsh-bilibili:8091` 连接，读取 `/data/partner/bilibili-bridge-token`；可通过 PARTNER_BILIBILI_URL / PARTNER_BILIBILI_TOKEN_FILE 覆盖。

凭证和幂等回执持久化在连接服务目录；Cookie 不返回浏览器或模型。评论/动态提交超时先保留未知状态，不能直接重发。请求串行与短间隔限制只是客户端节流，不保证绕过平台风控；遇到接口限制应暂停重试。

账号退出或删除渠道时清理登录凭证，公开浏览仍可独立运行。生产部署之前备份伙伴安装包与配置；回滚插件可以停止独立连接服务，保留其状态卷以便恢复。

## 视频与投稿（2.24.0-rc.2）

- 设置页采用 QQ 同款分层导航。公开能力无需登录，私有能力需要登录与独立总开关；自主活动只控制是否主动发起行为，不控制手动请求。
- `video_stream({bvid,page?})` 返回临时播放直链及必要请求头；可能是整体播放流、分段流或分离的音视频链接。不下载、合并、抽帧或分析，模型自行决定是否读取及如何处理。链接过期可重新获取。
- `upload_categories` 查询可用投稿分区；`upload_draft` 读取当前会话目录中的视频、封面，带标题、标签、简介、分区与原创/转载标记上传素材。转载需来源。
- `upload_status({job_id})` 查询进度。`draft` 表示本服务保存的待投稿草稿，并非 B 站创作中心云草稿；只上传素材不投稿。
- `publish_video({draft_id})` 单独授权并提交已上传草稿，返回 BV 号后仍受 B 站审核。重启或提交超时不会重发，需到创作中心核实。
- 每渠道最多一个上传任务，全局最多两个运行；媒体任务与回执持久化。暂存文件最多 512 MB、封面 8 MB，媒体暂存约 2 GB 配额，7 天过期时在下次媒体操作清理。本接口不会在会话目录中下载视频。
- 退出登录会取消本渠道未完成的媒体任务。不能从其他渠道查询上传稿件或读取视频。
