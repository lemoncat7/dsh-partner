# 滚动对话与公开回忆工具

开关在记忆设置的「对话窗口」，默认关闭，不修改已有配置。开启后下一次处理会话时生效，每次原生 pre-step 在生成请求前移出较早完整轮次。使用宿主的追加式 surface replacement，保留可重放的输入依据，完整原始事件不删除；不截改发送给模型的请求，也不调用压缩模型。关闭后停止继续滚动，不自动还原已经移出的工作窗口；原文仍可检索。

默认最近 20 轮和 48000 字符预算（对话正文及工具结果的序列化长度，非精确 token 数）。有完整工具执行的一轮视作整体；不拆工具调用与结果，不裁当前未完成的一轮。系统消息、开发者工具定义和系统快照不参与窗口裁剪。新轮次或当前任务过大、系统提示过大仍可能触发宿主容量保护，不承诺在任何输入下绝不压缩。

滚动期间暂停每日整段上下文焕新；保留原焕新开关和时间，关闭滚动后恢复原计划。学习和终审继续遵循各自开关，自动长期记忆仍以主会话为主，不扩大到全部群聊。

partner_memory_recall 是始终注册的公开基础工具，无需学习开关、归属账号或先加载工具。统一入口模式也直接显示此工具。私聊按当前人格先回应将回想什么，确认发送后再检索；没有长期记忆服务时仍能搜索当前会话原文。回忆结果分别标明用户和助手原话，限量返回摘录，不把助手历史当作用户事实，不将历史文字解释为指令。

原始对话检索只搜索当前真实会话；渠道消息使用持久来源记录，当前联系人不得读取其他私聊或群聊。历史旧版本未记录持久来源时仅使用仍可核验的渠道绑定，来源不明的旧记录不会推定属于当前账号；已有归档和长期记忆继续走原有检索。新网页消息也记录本地来源。不会因为回忆工具公开而把所有私聊归档复制到共同长期记忆。

### 2.22.1：上下文快照更新

滚动开启时，宿主的 `runtime-context`、`time-context` 完整快照会淘汰已被同来源更新快照完整覆盖的旧副本，不再随对话累积。具有独有章节的快照与第三方快照保留；系统、开发者指令与工具定义不受该清理影响。原始事件日志始终保留。
