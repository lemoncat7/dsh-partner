# 渠道消息格式

Matrix 发送 `m.text`，同时提供 Markdown 文本兜底 `body`、`format: org.matrix.custom.html` 及 `formatted_body`。Mattermost 使用其原生 Markdown `message` 字段。不改变微信发送逻辑。

使用 CommonMark + GFM 语法树解析和序列化，支持标题、强调、链接、引用、列表、任务项、表格和代码块。Matrix HTML 仅由白名单节点生成：原始 HTML 显示为文字，危险 URL 不生成链接，图片转为可点击链接而不是远程嵌入。具体视觉效果仍取决于接收客户端。

长消息按 UTF-8 字节预算拆分，普通块保持完整；超长代码块拆分后各自补齐围栏，超长表格重复表头，长列表保留序号。极端超长的单个行内单元、表格行或列表项转为字面代码分段，优先保证内容不丢失和符合大小限制，不保证这种极端情况保留原样式。拆分不截断 Unicode 字符；引用链接转换为独立链接，避免引用定义丢失。

普通回复、配对提示与主动通知复用同一个发送适配器。此改动没有实现远端消息编辑、附件传输或 Matrix 端到端加密，也不保证网络中断重试时多条远端分片恰好投递一次。

Markdown 依赖打包在服务端适配模块中，部署无需改动宿主依赖树。
