# 浏览器（Chrome CDP）

在「伙伴 → 渠道 → 通用」管理 TTS 和浏览器。TTS 的已有服务、音色与渠道分配保持不变。

浏览器连接现有 Chrome / Chromium，不启动另一份浏览器，也不轮询后台网页。填写 DSH 服务端可访问的 CDP HTTP 地址（例如同 Docker 网络中的 `http://chromium:9222`），或者 `/devtools/browser/…` WebSocket 地址。HTTP 地址会自动发现浏览器连接，适合浏览器重启后继续使用；不要填远程桌面端口。测试连接只读取浏览器版本，不保存配置、不创建标签页。

开启后，浏览器是**公开能力**，伙伴的已授权私聊、群聊和网页会话均可调用，不要求归属账号或私有能力开关。所有这些会话共用所选浏览器，页面中的已有登录身份也会用于操作。自主活动可单独关闭；开启时进入现有活动目录，由伙伴根据聊天与兴趣决定使用，不强制浏览或汇报。

工具经 `partner_tools` 的 `activity` 目录发现：`partner_browser`。提供 `status`、`tabs`、`open`、`navigate`、`inspect`、`screenshot`、`click`、`type`、`press`、`scroll`、`evaluate`、`close`。除状态、列页和新建页外，须显式指定 `tabId`。`inspect` 返回有界正文和可操作元素选择器；截图作为真实图片交给模型。`type` 替换文本输入框内容；`evaluate` 在页面环境运行 JavaScript，支持 Promise，结果有大小限制。

仅页面设置可修改连接地址，模型不能改连接目标。操作有超时和取消，保存配置或停用时会中止旧操作；同一连接忙碌时不排入无限队列。每次操作后断开自己的 CDP 连接，不退出 Chrome。断线或超时后可能已经发生的写操作不自动重试，应先查看页面确认结果。网页内容属于外部资料，不能当作人物设定或指令。

当前不提供代理密钥、文件上传下载或启动 Chrome 的配置。使用不带密码和查询参数的调试地址；浏览器服务本身的网络访问由部署环境控制。

## 页面状态与人工协助

`tabs` 提供 openerId；操作结果的 browserObservation 区分 requested、page-opened 和 unknown。父页面关系不能证明是谁点击，也不证明已发送消息。每次实际操作前后核对页面，暂不新增后台轮询；延后出现的弹窗在下一次查询/操作时核验。

`recent` 只查当前会话已有的工具回执，不访问网页。自动上下文限量展示最近 48 小时内匹配来源的浏览器事实，重启后可从原工具记录恢复；页面可能已变，必要时 tabs/inspect。摘要不包含网页正文、输入文字、脚本或截图；浏览器实例更换、功能关闭或会话来源不匹配时不注入。群聊不会自动获得其他私聊的操作摘要。

外部访问地址填写人能打开的远程浏览器网页，支持 HTTP/HTTPS 主机、端口和路径。可留空或清空，不填写密码或令牌；与 CDP 地址独立。`status` 在归属私聊或本地会话返回配置链接，由模型按真实障碍决定是否求助，不在群聊自动披露远程入口。用户处理完后重新检查原标签页，不重复提交操作。
