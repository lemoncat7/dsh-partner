# 提问来源与渠道头像

## 哪里发起，哪里提问

伙伴的主会话由网页、微信、Matrix、Mattermost 共用，但会话绑定不决定交互提问的去向。

- 每条渠道输入在送入 Agent 前记录其稳定消息 ID 与来源路由，保留每条路由最近 128 个 ID。来源记录随伙伴配置存储，重启后仍可读取。
- 提问时依据最新实际用户输入的消息 ID 判断来源；网页输入、未记录来源的旧消息使用 DSH 原生提问界面，不猜测微信或最近活跃渠道。
- 已发出的问题固定绑定原渠道和联系人，其他渠道或其他联系人不能代答。内部看板执行通知不会沿用上一条渠道输入发起提问。
- Matrix、Mattermost 的主接收循环等待执行完成时，交互问题使用独立的定向答复接收。先建立同步水位再发送问题，答复记入消息回执，避免随后被重复执行。
- 来源渠道停用、权限撤回或发送失败时明确中止，不静默把问题发送到另一个渠道。

## 修改自己的渠道头像

伙伴会话默认注册 `partner_channel_avatar`，无需单独开启能力：

1. `action: list` 查询当前伙伴自己的 Matrix、Mattermost 渠道。
2. `action: set`，指定 `channelId` 与会话目录中的图片 `path`。
3. 返回 `updated: true` 表示账号头像接口确认成功，客户端头像缓存可能稍后才刷新。

仅接收 2 MB 内的 PNG/JPEG；PNG 最大 4096 × 4096。拒绝 URL 自动下载、SVG/HTML、目录和越过会话目录的符号链接。凭据由插件内部读取，不进入模型上下文。

这是 **渠道账号头像**，不是 DSH 挂牌图案或房间头像。会影响该账号所有会话；不同伙伴共用同平台、同服务器账号时拒绝修改，应先配置独立账号。仅修改当前凭据确认的账号，不接受任意用户 ID。微信暂不支持。

接口：

- Matrix：`POST /_matrix/media/v3/upload` 上传图片，`PUT /_matrix/client/v3/profile/{userId}/avatar_url` 设置媒体 URI。
- Mattermost：`POST /api/v4/users/{user_id}/image`，multipart `image` 文件字段。

头像上传和设置间重新检查伙伴存在状态、会话归属与渠道配置；删除伙伴或变更渠道后旧工具也不能越权写入。失败返回错误，不声称头像已更新。
