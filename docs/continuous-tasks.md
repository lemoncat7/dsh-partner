# 持续任务

在伙伴的「持续任务」页面选择已授权会话和已打开的网页，填写陪看要求及结束条件。也可在聊天中让伙伴通过 `partner_tools` 的 activity 目录调用 `partner_continuous_task`。仅打开网页或写临时约定不算建立任务。

当前版本读取网页正文和 JSON-LD 文字直播更新，不读取视频画面、声音或跨域 iframe 内文。网页需自行加载动态内容；静态文章不会因反复读取变成实时直播。可用 CSS 选择器限定正文。浏览器或会话授权变化、页面跳转、来源不可读时会在面板显示原因。

默认每 20 秒程序读取，纯计数、时间、重复及排序变化不调用模型。新内容批次最早两分钟判断，后续至少三分钟合并；无新增时每十五分钟检查一次陪伴语境。检查不保证发送消息，也不因用户未回复而拉长间隔。实际发言由原会话按同一人物、关系、时间和最近对话决定。

同一伙伴最多三个未结束任务，共用每小时预算，默认 60000 token，可选 10000–200000。判断输入上限 3300 字符、输出上限 500 token，自动接话每次模型输出最多 700 token、最多三次请求。按真实模型用量结算，缓存输入也计入；没有用量回执保留保守预留，不自动重试。预算保护时继续程序观察。外部语音服务费用不属于模型 token 预算。

停止或暂停会先使旧执行失效再取消处理；重启保留观察基线与预算、不补发旧接话。普通一轮回答结束、沉默、局间休息不算任务完成。来源明确符合结束条件或用户明确结束陪伴才结束。暂停继续与新建不会关闭用户浏览器标签页。
