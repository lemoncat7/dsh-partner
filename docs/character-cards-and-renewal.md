# 人格强化与每日上下文焕新

人格强化是身份页中的可选能力。没有卡片或关闭开关时，继续使用原名字、角色、定位和行为准则。首次创建通过四步弹窗引导；已有内容直接展示和编辑。关闭开关保留卡片，应用草稿后需要保存身份。

开启后，角色核心、行为动机、语言风格、关系起点与对话示例成为持续生效的提示词约束。世界条目按最近交流中的关键词加载，每轮最多五条、正文总计最多 5000 字。任务、工具权限与 JSON 输出协议不被角色表现覆盖。模型遵循程度仍需试聊验证。

通用示例只用于创作起点。试聊使用伙伴模型，最多保留八组对话，不使用工具、不写入正式记忆，也不会发送到渠道。独立试聊支持预览未保存的草稿。

“当前相处状态”统一放在记忆页，共用上方记忆范围和学习开关；角色聊天开启时，后台记忆提炼一并维护当前话题、明确关系及必要的近期互动，不增加独立任务或串行调用。默认折叠，背景与固定内容按需展开；已有角色状态原位保留，固定内容仅由用户修改，并使用版本检查保护较新的编辑。长期事实、偏好与约定仍进入有证据的长期记忆，相处状态不重复人格卡或长期画像。做梦独立保存联想，不得将梦中内容当成共同经历。学习关闭后暂停自动整理；角色聊天关闭后停止状态注入，但已有内容仍可查看、修改。

## 每日上下文焕新

- 独立开关，默认开启；独立时间，默认每日 04:00，使用插件配置的时区（默认上海）。不依赖每日终审开关。
- 开启记忆：先补齐当前上下文中未归档的旧消息或中断消息，再等待逐轮提炼完成，再补齐包括当天已有对话的终审。所有待整理内容成功落库、当前可见用户消息确认已归档后，才释放上下文。
- 关闭记忆：到点且空闲后直接释放上下文，不等待提炼或终审，也不声称已经记住这些对话。
- 当前回合、后台记忆任务或会话准备未结束时延后；失败保留原上下文并重试。每日终审原有的重试退避仍生效。
- 服务在当天计划时间之后启动时，等待下一次计划，避免部署或重启立即清空上下文。
- 同一会话每日最多焕新一次。焕新使用 DSH 的 `runMaintenance` 和原生 surface replacement，保留第一个系统节点，不改写原始日志文件；聊天历史仍可查看。
- 记忆开启时保留简短的近期日记与未完成事项交接；身份和角色状态由系统段重新载入，具体旧细节按需检索，不把全部历史重新塞回上下文。

历史检索覆盖记忆库中保留的原始对话，包含中文二元词索引和英文标识，解除原先“只查最近 100 轮”的限制。`partner_memory_recall` 只能查询当前伙伴、当前联系人的范围；默认返回有限条带时间与来源的片段。用户设置的历史保留期限仍然有效；未启用记忆时未归档的内容不能由此工具恢复。相关信息召回不等于保证每个细节都自动记得。

关闭每日终审只关闭独立的日记终审计划；如果“每日上下文焕新”开启且学习开启，焕新前仍会进行必要的整理。想保留工作上下文，应关闭“每日上下文焕新”。
