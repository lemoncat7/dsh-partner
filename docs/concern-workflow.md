# 持续关注的依据与步骤流程

持续关注不创建看板。检查器负责判断变化和执行资格；开启后续执行时，把核实结果、文档步骤和绑定依赖交给伙伴原会话。

## 读取 → 识别 → 核验 → 交接

1. 笔记通过 `heartbeat_read_note_source`，知识文档通过 `heartbeat_read_knowledge_source` 定向分页读取。知识标题保持原样，不删词做模糊召回；读取仍受当前会话挂载、标签限制。明确绑定到单份文档时，宿主只为这一份依据提供跨项目只读访问；仅绑定整个库不授予跨项目访问，普通知识搜索/读取保持项目限制。关注停止、删除、依据变更时撤销定向访问。本地依据使用原会话文件读取权限。
2. 模型从正文、编号步骤、表格和段落识别检查与执行步骤，使用 `heartbeat_check_workflow` 保存每步来源、方法/前置条件、完成标准。不硬编码站点、代理或发布平台。
3. 检查步骤完成或受阻时更新证据，可用 `update.updates` 批量登记，也可在最终观察的 `workflowChecks` 数组一次提交 `{stepId,status,evidence}`，包括最后的无工具收尾轮。批量校验全部通过才更新，不允许完成执行步骤、重复步骤或空证据；无需为了登记每条状态额外调用模型。待执行的成稿/生成/发布步骤不能算检查失败；明确要求在检查中核验的条件也不能被移到执行阶段绕过。
4. 检查成功须有完整依据和完成的检查步骤。未满足时给予有界纠正机会，仍未完成则受阻，不派发执行。模型的语义理解仍需真实来源证据支持，流程校验不等于外部事实自动证明。
5. 完成的观察携带步骤交接，沿用稳定执行键去重并直接注入伙伴会话；不新增看板、定时任务或通知授权。未开启执行时，文档不能自行授予执行权限。

## 续跑与版本

脱敏工具摘要和步骤清单持久化到已有关注存储。重启后重新读取当前依据、识别流程，旧证据仅供参考；不能把上次成功当作当前时效数据。分页期间依据 revision 改变会撤销旧清单，要求从头读新版本。失效或撤销的授权不会被恢复记录绕过。

检查产物的记录同步仍是独立持久任务。`heartbeat_record_checkpoint` 按字段区分未知关注、未选记录位置、核验不完整、data 类型/长度、instructions 类型/长度错误；同步失败不应伪装为来源检查失败。

部署不会自动重放旧发布任务，避免重复草稿或公开发布。用户请求复测时从现有关注入口触发，先核对已有交付；旧观察无步骤清单仍可读取，后续新检查使用新流程。多候选关注每轮优先闭环一个事项，除非明确要求全量核验，不让无关候选阻断已核实事项。

JSON 工具结果逐字段脱敏，避免凭据行吞掉后续证据；网址在中文标点、Markdown 代码边界和换行前截止，保留其后的正文。续跑摘要仍有长度上限，截断部分必须重读。

检查器拥有独立的临时 Agent 标识，但保留原会话对象和继承的权限作用域。它不会以原聊天 Agent 的身份注册后台作业；官方 bash 工具在没有可注册作业的会话所有者时回退到有界前台执行。检查命令最长 50 秒，检查结束后不再通过作业完成通知唤醒主聊天。正式后续执行仍在原会话正常运行，不受此限制。

每项检查保留 12 轮实质核验，纯依据读取、记录基线读取、步骤登记和检查点保存最多另外占用 8 轮；只有整轮这些工具均成功才计入准备额度。混合调查、工具失败、无工具纠正轮仍消耗核验额度，总共最多 20 轮工具交互加 1 轮收尾。独立记录同步维持原来的 12 轮上限。

## 模型连接异常

单轮模型请求遇到临时 500/502/503/504、连接重置、TLS EOF 或 HTTP/2 协议中断，分别退避 1 秒和 3 秒，最多补试两次。所有尝试共享原有 180 秒时限，不重置超时。失败流中的部分文本和工具调用丢弃，已执行工具的结果保留；工具执行不在重试边界内，所以不会重放生成、记录或发布操作。

认证、参数、证书和取消错误不短间隔重试，429 交给现有调度策略处理。心跳记录显示退避次数；重试耗尽仍如实报告失败，不能保证不可用的上游服务恢复。

## 验证与维护边界

- 已验证从绑定依据读取、检查、记录同步到原会话草稿执行的链路；恢复前核对已有文件、外部素材和操作记录，复用已有产物，不重复提交。
- 区分“事实已记录”与“交付物已完成”，每项关注使用自己的执行条件，不套用其他关注的选题门槛。来源、未知事实和测试范围仍须如实说明。
- 读取依据返回 `sourceKey`；步骤 `source` 格式错误时指出步骤 ID 和当前关注的可选值，不跨关注暴露来源，不部分保存无效清单。
- 回执识别忽略宿主标注的自动压缩检查点，仍拒绝中断、无最终答复及被真实新用户请求隔开的结果。仅核对结果模式不重放外部操作。
- 外部接口成功和内容回读不等于手机端视觉验收，更不等于已公开发布。具体用户内容、草稿与操作编号不属于公开插件文档。
