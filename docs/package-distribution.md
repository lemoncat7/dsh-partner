# 安装包资源范围

小说改编互动游戏的内置发行包保留全部七个技能模块、参考资料、入口、MIT 许可证和固定版本来源；不分发上游 `examples/` 中已完成的示例游戏、图片、剧情数据及示例项目的运行/验收脚本。

这些示例仍可保留在源码仓库中供维护者查阅。该资源目录的 `.npmignore` 阻止它们进入 npm 安装包；顶层 `manifest.json` 仅列出实际安装的资源，安装和导出均使用此清单。`upstream/manifest.json` 是未改写的原始快照来源记录，不是当前发行包的文件清单。

上游 README 保留原文，其示例链接应到固定提交的上游仓库查看，不承诺示例文件存在于安装目录。技能入口也明确说明该区别。其他技能的脚本、参考资料、卡牌渲染代码及调试映射均不在本轮精简范围。

后续离线导入使用 `scripts/bundle-story-skills.mjs`，它仍核对源快照哈希，但按 `scripts/story-resource-policy.mjs` 的规则过滤可选示例并生成发行清单及 npm 排除规则。

发布前先构建和打包，再执行 `npm run pack:verify -- /absolute/path/to/package.tgz`。检查实际压缩包不含可选示例、体积不超过 10 MB，并从解包目录加载所有内置技能，核验文件完整性和哈希。不要仅凭源码测试判断发行包可用。
