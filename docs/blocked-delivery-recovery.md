# 受阻通知与外部结果检查

需求阶段汇报和独立任务受阻通知只发送文字。只有成功完成后的最终交付才发送产物附件。受阻时不再生成额外汇报文档；旧的未完成通知在重试时也清除待发附件，保留已确认发送的文字回执。

看板外部等待的唤醒轮只允许查询已有外部任务。查询执行异常、超时或缺少 resolve 回执时，在原检查次数和截止时间预算内退避重试同一外部 ID。权限/工具缺失、取消、明确 blocked 回执和预算耗尽仍进入受阻协调。普通独立续接可能已执行后续动作，不自动重放。

这不是自动重新生成。画布明确 failed 的任务不会因查询而重启；原 requestId 也只重放原任务结果。创建者应先核实上游接单、计费与已有产物，只有在用户授权范围内且成本明确时决定新的生成尝试。不能用新 requestId、重复定时任务绕过预算或无限重试。
