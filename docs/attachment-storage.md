# 附件交付副本

交付副本为不可变快照，用于历史下载、验收证据及渠道失败重试，并非原始工作文件。
全部伙伴共享额度（默认 512 MiB），在「设置 → 基本设置 → 附件存储」修改。
额度持久化，降低额度不自动删除数据；单文件上限仍为 64 MiB。

新版存储统一位于 `storage-v1/attachment-deliveries/`：根目录放 SQLite 索引，
`<伙伴编号>/<交付ID>` 保存副本。启动时将原根目录平铺文件校验后移动到伙伴子目录，
原 ID 和链接不变；中断可续接，冲突时保留源文件并停止迁移。
未进行目录版本迁移的安装仍使用原公共 `attachment-deliveries/`。
历史 `partners/<id>/.partner/deliveries/` 在启动时逐份复制、校验、提交后移除旧副本；
空旧数据库保留供迁移核查。重启可续接，交付 ID、重试路由及历史链接不变。
部署前应停止服务并备份公共数据及伙伴私有目录；回滚旧代码需同时还原附件存储。

清理只能在设置中明确选择并确认：保护待发送/失败重试、最近五分钟创建及活动任务/需求引用。
清理后原始文件不变，但对应历史下载链接失效，不能撤销（除非从管理员备份恢复）。
删除伙伴并选择删除其文件时，也清理该伙伴的公共交付副本。
不要直接批量删除目录中的文件，应通过设置保持文件与索引一致。
