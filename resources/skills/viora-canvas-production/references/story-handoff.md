# 小说与漫剧分镜交接

这是文件交接约定，不是 MCP schema，也不会自动启动后台流水线。仅写小说或审稿时不启动制作。

## 来源和分工

小说技能提供章节、人物设定、事件顺序和改编范围；漫剧技能提供剧本、分镜、图片/视频提示词和参考需求；画布技能负责节点、真实素材、任务和结果。已有分镜直接消费，不重做改编；只有正文时先按用户授权改编，不把整章作为视频 prompt。
先读已有项目。常见输入是正文、设定/追踪及 `剧集/<EP>/` 下的 `剧本.md`、`图片提示词.md`、`分镜.md`、`视频提示词.md`、`制作成果/`，但以用户实际路径为准。其他技能未安装/未启用时不调用不存在的模块，可消费已有文档；缺能力说明缺项，不自动安装或授权。

## 保留编号与依据

| 来源 | 含义 | 画布对应 |
| --- | --- | --- |
| 章节路径、版本、段落定位 | 原作依据与改编范围 | 来源 note，不重复全文 |
| 人物/场景/道具标识及造型/状态版本 | 连续性约束 | 文字设定与认可基准 image 分开 |
| IMG 条目 | 图片提示词，不是已生成图片 | 图像生成意图 |
| SHOT 条目 | 分镜和冻结起始帧 | 镜头 note / 静帧生成意图 |
| MOTION 条目及其源分镜 | 动作、机位、起点、状态链、终点 | video 节点和完整动态 prompt |
| REF 槽位、顺序、用途 | 真实可读的图片 | 资产、image 节点、有序稳定 URL |
| PLAN、待补素材 | 计划中的依赖 | blocked，不写入 inputUrls |

保留完整来源键，如 `EP01/分镜.md#SHOT-001`；不同分集同号不合并。没有编号才建立稳定编号，不强迫改写源文档。nodeId/jobId/assetId 必须来自工具回执，不用创作编号冒充。

## 素材就绪

- REF 必须核验文件或资产，保留顺序、用途、控制范围和不得控制范围。路径相对于来源项目，不是技能目录；只读已授权路径。IMG/SHOT 编号不是文件，PLAN 不是真实参考。
- 本地图片若未导入画布，检查实际工具 schema。有 `viora_asset_upload_local` 时按 begin → 用返回临时 URL/请求头 PUT 原文件字节 → complete，保留真实 assetId、稳定媒体 URL 和可选 nodeId。服务端不能读取 DSH 本地路径；无上传能力先请求导入，不把本地路径填入 inputUrls。临时凭据/签名 URL 不进永久台账，不在对话塞 Base64。
- “无”“待补参考图”不等于文生视频授权；仅创作者明确选择且模型支持才走无图方案。
- 冻结起始帧不是结束帧，结束帧应有独立来源条目及真实素材。模型不支持某类参考/首尾帧时说明选择，不静默改变用途或丢图。
- 参考数量、时长超过模型限制时提出拆镜/选图/换模型，不静默截断或缩短已批准镜头。

## 交接台账

沿用现有制作台账；多镜头无台账时在用户项目建立 `画布交接.json` 或等价 Markdown。它是本地记录，不直接传给 MCP：

- 来源：项目/分集、文件路径、条目 ID、版本或内容哈希、原作定位、负责人及确认状态。
- 创作：角色/造型/场景状态、时长、画幅、静态与动态 prompt 各自来源。保留原文，另记实际提交 prompt。
- 参考：每个 REF 的顺序、用途、真实路径/资产与认可版本；每个 PLAN 的就绪条件。
- 映射：projectId、来源条目 → 生成 nodeId → resultNodeId/assetId；不只靠标题猜对应关系。
- 尝试：kind、模型、有效参数、有序参考、requestId、jobId、查询时间、实际状态、canvasSync、验收结果。无回执字段留空，历史尝试追加不覆盖。
- 变更：来源版本、受影响镜头及下游、旧结果是否认可、下一动作和授权预算。

## 修订与续接

复用须核对来源条目、版本、用途、有效参数与参考，不是文件名相同就复用。续接先读源文档、台账、画布和已有 jobId；queued/running 只查询，canvasSync 未完成只修同步。
完全相同参数的网络重试复用 requestId；改变实际 prompt/参考/模型/参数才算新意图，须在授权预算内，不靠换 ID 绕过冲突。
改稿先标记受影响镜头待复核，保留无关镜头和认可结果；不等于授权整集重拍。生成期间来源变化，旧结果记为旧版本候选，不覆盖新映射。冻结/完成文档按项目修订批准规则处理，不偷偷改写。
每个生成意图只有一个执行负责人；其他伙伴检查或交接，避免重复投产。画布完整节点更新与版本冲突仍遵守 canvas-contract.md。
succeeded、创作验收通过、画布同步成功、附件已送达分别记录。最终按镜头列出真实结果、未就绪依赖与下一步；视频卡片不代表已剪辑合片。
