# 人物、场景与分镜

## 人物基准

为每个主要人物分配稳定创作编号，例如 C01；它不是画布节点 ID。记录必须保持的身份要素：年龄段、脸型、发型与发色、体型比例、服装层次和主色、标志物。表情、姿态与镜头光线是可变项，不能混进永久身份。

按需求选择单人基准图、正侧面或服装细节。不要默认生成三视图拼图：若后续模型只支持一张参考，清晰单人图通常比复杂设定板更可控。多人共图要能明确辨认身份，否则先拆成人物基准。

生成后实际读取预览/图片进行核对；无法视觉检查时明确标为“待视觉确认”。有可用结果不等于已经认可。保留认可的 assetId、mediaUrl、节点 ID 和版本，失败尝试不替换认可版本。

## 场景基准

为主要场景分配 L01 等编号，记录时代与空间、关键入口/窗户、人物活动区、道具位置、光源方向、时间和天气。先生成建立空间关系的全景；只有镜头真的需要时再补反向或细节参考。

同场景的近景应继承空间/材质与光线，不必把基准全景当成必须照抄的构图。人物与场景参考在提示词中分别声明用途，避免模型把场景参考中的路人当主角。

## 镜头清单与分镜图

每镜 S01 等编号只表达一个主要叙事动作，记录：

| 字段 | 决策用途 |
| --- | --- |
| 叙事目的、动作起止 | 避免一个短镜头承担多个互斥动作 |
| 人物与场景版本 | 明确使用哪份已认可基准 |
| 景别、机位、视线/轴线 | 保持空间连续性 |
| 人物位置、道具、光线 | 防止左右手、服饰、环境漂移 |
| 时长、镜头运动 | 视频模型能否实现，不能只按剧本总时长硬填 |
| 参考图次序及职责 | 与实际 inputOrder、inputUrls 对应 |
| 验收要点 | 判断结果可用，限制重试范围 |

先生成分镜**静帧**再动画化，适用于身份/构图一致性优先的任务。用户明确只要文字分镜、单张图或直接视频时，不强制增加这一步。

单帧提示词按“参考职责 → 主体与动作 → 空间构图 → 摄影光线 → 风格 → 本镜约束”组织。不要直接把整份剧本作为单镜 prompt；画布文字连线也不会替你拼接提示词。

例：S03 使用输入 1 的 C01 人物身份，输入 2 的 L01 场景布局；人物位于画面左侧、看向右侧门口，中景，镜头不越过既定轴线。把“输入 1/2”解释与真实数组顺序同步，而不是凭文件名猜序。

只有一张参考的模型：先基于人物和场景生成一张合成分镜图，再用这张已核验分镜作为视频参考；不能把不支持的多图硬塞进请求。

## 从分镜图到视频

视频 prompt 重点描述时间中的变化：起始姿态、主动作、终止状态、速度、允许的镜头运动。保留身份与空间条件，避免用相互矛盾的镜头运动。

- 自由参考模式：图片用于身份、物体或环境，不承诺按输入顺序变换成连续画面。
- 首尾帧模式：只有当前模型和适配器明确支持时使用，输入顺序就是起点与终点。
- 当前 Grok 视频适配器拒绝 keyframes；不要把两张图说成原生首尾帧。
- 用户想要的总时长超出单次能力时，提出按动作边界拆镜和后期拼接方案。当前 MCP 没有视频剪辑导出工具，不虚构自动合片。

## 修订范围

先指出偏差属于身份、场景、构图还是动作。只调整对应 prompt/参考/参数；保留不变的基准。一次先验证一个代表镜头，确认后再扩大批次。无法继续满足授权预算时停止新增生成，交代已产出和差距。
