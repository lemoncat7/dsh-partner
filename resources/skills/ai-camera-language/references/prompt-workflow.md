# 应用流程与示例

本文件是基于视频镜头词典扩展的执行方法，不是原视频逐字内容。无需调用特定 MCP 或视频平台即可输出文字方案；真正提交生成需遵守用户授权和目标平台实际协议。

## 1. 从故事或小说到可拍摄镜头

先提取：场景、出场人物、可见动作、关键道具、空间关系、叙事转折。内心描写若不能直接拍摄，建议以动作、表情、声音或镜头关系呈现；明确这是改编选择，不擅自新增人物动机或事件。

一个叙事节拍通常对应一个观众需要获得的信息。例如「看到信封 → 打开 → 读到消息 → 看向门口」可以拆成几个镜头，也可以根据用户时长和一镜到底要求，设计连贯的单镜头。不要固定每个句子一个镜头，也不要为了展示 32 种技巧强行扩写故事。

给每个镜头分配注意力目标，再选择是否移动摄影机：

| 目标 | 可选策略，非强制对应 |
|---|---|
| 交代空间关系 | 固定全景、拉镜、高角度、顶拍、航拍 |
| 观察表情变化 | 固定近景、推镜、前跟镜 |
| 从细节转到另一个信息点 | 拉焦、摇镜、遮挡揭示 |
| 跟随人物行动 | 前跟、侧跟、后方跟随推进 |
| 强化空间或动作的主观异常 | 荷兰角、滚转、变焦推拉 |
| 展示路径与进入过程 | 穿越、贴地穿越 |
| 展示主体周围关系 | 环绕、低弧绕行、螺旋上升、环绕下降 |
| 让观众占据某个角色的位置 | POV、过肩构图 |
| 强调一个凝固瞬间 | 子弹时间；不默认替换成普通慢动作 |

同一个目的可以有多种选择，说明所选方案最重要的一条理由即可。

## 2. 统一镜头描述的维度

把模糊提示拆成不同维度，便于定位冲突：

| 维度 | 需要时写清 | 常见错误 |
|---|---|---|
| 主体 | 谁、正在做什么、速度和朝向 | 主体前进被写成摄影机推进 |
| 机位 | 前／后／侧、距离、高度 | 要求前方正面同时拍完整后背 |
| 朝向 | 看向哪里、是否跟随转向 | 横移中既保持世界朝向又始终对准近处主体 |
| 路径 | 直线、弧线、升降、经过的开口 | 穿越封闭门板却无超现实设定 |
| 焦距 | 固定、变长、变短 | 把 zoom 与 dolly 混用 |
| 焦点 | 哪个对象清晰，何时切换 | 把拉焦写成把镜头拉远 |
| 构图 | 起始与结束景别、主体位置 | 全身恒定构图却突然变面部特写而无过程 |
| 节奏 | 缓慢、匀速、突然、加速、停稳 | 一段同时要求全程匀速和突然加速 |
| 稳定性 | 固定、稳定跟随、手持微晃 | 绝对无抖动与剧烈手持并列 |

无需为每条提示词填写整张表。只用足以控制该镜头的维度。

## 3. 提示词组织

推荐的自然语言顺序：

> 主体与动作 → 场景和起始构图 → 摄影机运动 → 结束画面 → 少量关键连续性约束。

故事没有要求时，不自动增加角色服饰、台词、品牌或剧情反转。「电影感」「高级感」可以是审美目标，但不能替代实际的机位、光线、运动和构图。

原片关于更具体描述的建议，不等于把提示词写得越长越好。优先删除无作用的重复形容词，保留能够区别目标镜头的条件。

中文通常可以完整描述运动。用户需要英文时，再用词典中的术语加物理过程；不能承诺英文一定更稳定。模型已有专用运镜控制时，只有核验其实际取值后才提供参数映射。

## 4. 参考图与连续性

- 参考图作为首帧时，从图里真实存在的主体、景别、机位与空间关系起步。不能把正面近景当作背后远景起点，却不说明需要重新生成首帧。
- 静态图片本身不能展示时间过程。静帧提示词负责角色、布局和构图；视频提示词负责动作与镜头随时间的变化。
- 环绕或大幅移动会暴露参考图看不见的侧面或背面。若角色一致性很重要，说明这一限制；可建议补充视角或降低幅度，但不谎称单图提供了完整三维信息。
- 跨镜头维持服装、道具位置、人物视线和运动方向；有明确场面调度时按它执行。改变轴线或方向可以是创作选择，不能无意识发生。
- 已有分镜只需增补运镜时，保留镜号、剧情、台词与顺序。若用户要改写剧情，再进行结构调整。
- 时长、参考图数量、首尾帧支持和分辨率由具体模型决定。本 skill 的「建议 4 秒」是叙事安排，不是 API 能力声明。

## 5. 默认输出的轻量结构

只要一条提示词时，给成品与必要解释，不输出长篇教学。

分镜任务可以采用：

| 镜号 | 建议时长 | 叙事信息 | 主体动作 | 起止构图 | 机位与运动 |
|---|---|---|---|---|---|
| S01 | 根据用户预算安排 | 观众本镜要看懂的事 | 可拍摄的动作 | 起点 → 终点 | 主运动及必要补充 |

表格后按镜号提供可复制提示词；用户要求结构化数据时可改为 JSON。下例仅为已填充的中间分镜示例，不是任何厂商的 API 请求：

```json
{
  "shot_id": "S01",
  "duration_seconds": 4,
  "duration_status": "editorial_suggestion",
  "intent": "让观众发现桌上的信封",
  "subject_action": "人物把钥匙放到信封旁边",
  "camera": {
    "position": "桌面前方，略高于桌面",
    "movement": "locked-off",
    "lens_change": "none",
    "focus_change": "none"
  },
  "prompt_zh": "固定机位拍摄桌面中近景，信封位于画面右侧。一只手进入画面，将钥匙轻放在信封旁，随后退出。保持桌面布局和焦距不变。"
}
```

不要擅自把 `movement` 中的示例字符串视为目标平台接受的枚举。

## 6. 完整示例：20 秒小说片段分镜

输入故事：雨夜，女孩回家，在桌上发现信封，读完信后转头看向敞开的门。

设计约定：20 秒，5 个镜头；以下分镜是 skill 应用示例，不是视频作者提供的故事。固定机位和硬切保留，不用运镜覆盖每一秒。门原本就敞开，不额外编造有人开门或门外出现人物。

| 镜号 | 时长 | 叙事目的 | 构图与运动 |
|---|---|---|---|
| S01 | 4 秒 | 交代回家和空间 | 室内固定全景，女孩从敞开的门进入 |
| S02 | 4 秒 | 发现信封 | 桌面中近景，短距离推向信封 |
| S03 | 5 秒 | 读信 | 肩后中近景，摄影机稳定 |
| S04 | 3 秒 | 观察转头反应 | 固定面部近景，保留她的转头动作 |
| S05 | 4 秒 | 呈现她看向的目标 | 女孩的 POV，固定观察敞开的门 |

总时长：4 + 4 + 5 + 3 + 4 = 20 秒。独立镜头之间直接硬切。

### S01 成品提示词

雨夜的室内，固定机位全景拍摄房间，敞开的门位于画面左侧，桌子位于右侧。女孩从门外走进房间，朝右侧桌子走去。摄影机不移动，保持人物服饰和室内布置一致，门始终敞开。

### S02 成品提示词

同一房间，桌面中近景，一封信静置在桌上，女孩的手在信封旁停住。摄影机缓慢向信封直线推进，由桌面中近景收紧到信封特写，焦距不变，焦点保持在信封上。女孩的手不遮住信封，不新增可读文字。

### S03 成品提示词

从女孩右肩后观察她手中的信，肩膀与少量后脑占据右侧前景，信纸位于画面中部。女孩展开信纸并停下来阅读，摄影机保持稳定，不变焦，不切换到她正面。无需生成清晰可读的信中文字。

### S04 成品提示词

女孩面部近景，摄影机固定在她正面略偏侧的位置。她从低头看信缓慢抬起视线，随后转头望向画面左侧的门口，最终视线停住。只表现这一反应，不新增哭泣、惊叫或额外人物。

### S05 成品提示词

从女孩站在桌边的位置，以她的第一人称视角看向敞开的门。固定机位停留在门框与门外雨夜的画面，门保持敞开，不出现女孩自身，不新增门外人物。

说明：没有让生成模型承担未指定的信件内容或精确文字渲染。用户要求出现信中文字时，可另给文字内容并建议后期叠加，而不是保证模型逐字生成成功。

## 7. 单镜头修订示例

### 例 A：混淆推镜和变焦

用户原稿：「固定机位，镜头向前推，慢慢变焦靠近面部。」

若用户要靠近人物带来的空间变化，改为：

> 摄影机从人物正面中景开始，缓慢直线向前推进，焦距不变，最后停在面部近景，焦点始终位于人物眼睛。

若用户明确机位必须固定，则用光学变焦版本：

> 摄影机位置与朝向保持固定，缓慢拉长焦距，从人物中景收紧到面部近景，不进行摄影机前移。

不能把两者混成一个自相矛盾的成品。

### 例 B：环绕却不想让人物转身

> 人物静止站立并保持朝向不变。摄影机从人物正前方开始，以俯视下顺时针方向绕行四分之一圈，终点方位与起点相差 90 度。保持相同高度和距离，镜头持续朝向人物，背景随摄影机位置自然变化。

这里指定的是摄影机轨迹，不是「人物旋转 90 度」。角度属于视觉目标，不承诺每个模型精确执行。

### 例 C：静止主体的子弹时间

> 冻结人物跃起的瞬间，衣角和周围水滴同时悬停在原位。摄影机从人物正前方缓慢绕向侧面，观察这个凝固瞬间；人物、水滴与衣角不继续运动，摄影机运动保持连续。

若生成结果变成全画面定格，检查是否把摄影机也包含进了「一切静止」；若变成慢动作，强调冻结的空间位置，而不是追加更多 slow motion 词。

### 例 D：双语拉焦

中文：

> 摄影机固定在桌前，焦距与构图不变。前景钥匙起初清晰，背景人物模糊；随后焦点缓慢从钥匙转到人物眼睛，钥匙变虚，人物眼睛变清晰。摄影机不移动、不变焦。

English:

> Lock the camera in front of the table, with focal length and composition unchanged. Begin with the foreground keys in focus and the person in the background blurred. Slowly rack focus from the keys to the person's eyes, letting the keys soften as the eyes become sharp. Do not move the camera or zoom.

## 8. 失败后的最小修订

| 观察到的失败 | 优先核对 | 修订方向 |
|---|---|---|
| 主体转了，摄影机没绕 | 是否只写了「旋转」 | 主体保持朝向，明确摄影机绕行路径与背景变化 |
| 推镜变成画面放大 | 是否同时写 zoom | 保持焦距，描述机位前移与前后景视差 |
| 拉焦变成镜头切换 | 是否只写「从 A 到 B」 | 固定机位、焦距、构图，明确虚实互换 |
| 视角方向错误 | 「左／右」的参照是否模糊 | 用摄影机视角或俯视方向，再写终点方位 |
| 贴地穿越撞穿障碍 | 起点、开口和路线是否冲突 | 明确开口已打开、可通行路径和终点 |
| 环绕导致角色外形变化 | 参考图是否只有一个角度 | 降低暴露新侧面的幅度，或建议补充参考视角 |
| 多种运镜都不明显 | 同一段是否塞入太多变化 | 保留叙事最关键的一个机制，其余拆镜或删去 |
| 同一错误反复出现 | 是否已排除提示歧义 | 说明可能是模型能力限制，不承诺多重试一定成功 |

只做文字方案时可给简化备选。需要实际试生成时，先确认所用平台、可用能力与用户允许的次数或预算；不能因为 skill 推荐测试就自动进行无限付费重试。
