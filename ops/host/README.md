# 已回收工作会话的原生目录清理

伙伴原先只删除子会话存储，原生 `subagentCatalog` 仍保留创建记录，页面会显示不可用的灰色子智能体。`subagent-catalog-cleanup.mjs` 为尚无目录删除事件的宿主提供小范围兼容补丁：识别伙伴追加的 `plugin:dsh-partner/subagent-cleaned` 忽略记录，移除目录中的对应项。原有目录内容及其他子智能体保持不变，继承前缀里的清理记录无效。目录投影状态版本从 6 升到 7，旧缓存重新计算。

插件仅在确认工作会话已终结、成果已回传且子会话日志已删除后追加清理记录；运行、待交付和无归属依据的记录不能触发。插件验证原生 `listDescendants` 确实不再返回目标后，才标记目录清理完成。未加载支持时保留重试状态并记录原因。已经删除日志的旧任务也会补清目录。

清理使用会话原生追加和持久化接口；不重写主会话、不改变原消息序号、不重新压缩历史，作品与任务结果保留。该记录不进入模型可见消息。卸载兼容补丁的旧宿主可保留并忽略记录，灰色目录可能重现，聊天历史仍可恢复。

部署前对实际宿主源码运行 `patchSubagentCatalog(source)`；该函数只接受已识别的目录实现，拒绝未知实现，并支持幂等检查。验证原生目录折叠、重放、缓存版本、无效/继承记录、保留运行中的其他子级，以及原生会话格式恢复后，再备份和原子替换实际宿主入口文件，并在无前台/后台工作时重启。宿主升级覆盖入口文件后，应重新核实是否已有原生支持，不能盲目重复套补丁。此补丁不修改宿主版本检查。

目录隐藏仅影响发现，不释放名称。名称分配同时读取父会话所有自有 `subagent/catalog` 事件，保留已回收名称；继承前缀不占当前父会话名称，原生并发预留继续有效。原生 v4 格式要求整个自有历史中名称唯一，不能仅按可见目录分配后复用 `agent-1`。已出现的重名必须在停机、备份后最小修复目录元数据，并经过真实格式恢复验证。


## 取消后继续同一伙伴任务

`background-continuation.mjs` 给此版本宿主补充 `resumeActivation`。它通过原生冷恢复与同一 childId 重新挂接单次执行所需的结构化输出契约和 `delivery: caller`；不追加 catalog、不复制前台历史，不调用 provider 的空白创建准备。目标树和 provider 在恢复时核验，接收消息时再次核验 provider，运行中或正在关闭的激活按原生锁处理。默认 sendMessage/deliverPrompt 行为保持原样。

伙伴 `cancel` 释放运行资源并保留日志，`resume` 仅接受原来源会话的明确请求，沿用工作目录、任务 ID 与子会话 ID；成功结果仍交前台再回渠道。`discard` 明确永久放弃后才允许清理取消的任务。已完成且已交付的工作照常清理；重启后未完成工作转为等待明确继续，不自动重跑。已经删除的旧日志无法恢复。

部署前用实际宿主源码运行补丁并检查幂等。`verify-background-continuation.mjs <补丁源码路径>` 在生产依赖版本下以隔离 mock 验证真实 SubagentManager 的恢复、输出契约、原名称、无新 catalog、活动重复拒绝、provider 与树隔离；不会发起模型请求或渠道消息。原生依赖默认取 `/opt/dsh-022/lib/node_modules/@deepseek-ai/dsh/node_modules/`，只适用于已经核对的部署。


## 首轮工具准备边界

`prepare-tools.mjs` 在宿主 `dsh-agent-loop` 的 `preStep` 中，于原生 `tools.resolve()` 冻结本轮可执行集合之前，等待带真实 Agent 作用域和待接收消息的 `agent/prepare-tools` 事件。伙伴在这里安装恢复会话的工具与权限投影；已有组合缓存避免每条消息重新注册。渠道获取已有或新建 Agent 时也显式等待准备完成。

仅在提示词 assembly 或之后的 pre-step 回调注册工具，无法补回此前冻结的执行集合，会造成首轮 `UNKNOWN_TOOL`。本补丁保留原生工具准入和调用权限，不通过失败后自动重试外部写入补救。准备失败或取消时，本轮在工具快照前停止。

部署只接受已识别的宿主实现，备份并原子写入实际入口；宿主升级或重建容器后需要重新核对。`verify-prepare-tools.mjs <实际宿主源码>` 执行抽取的原生 `preStep`，验证准备完成后才冻结工具、准备异常和取消均不进入冻结步骤，以及补丁幂等；它使用 mock 工具服务，不调用模型或发送渠道消息。另有真实工具运行时的首轮执行和权限回归测试。
